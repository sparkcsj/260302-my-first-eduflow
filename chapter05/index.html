    Chapter 05. 두 번째 실습: 내 전공어로 만드는 Word Cloud¶

    🎯 이 장에서 배우는 것¶

    • 텍스트도 분석할 수 있는 데이터라는 것을 알 수 있다
    • 자신의 전공어 텍스트로 워드클라우드를 만들 수 있다
    • 데이터과학과 언어 공부의 연결고리를 발견할 수 있다

    📚 핵심 개념¶

    개념 1: 텍스트도 데이터다¶

    지난 시간에 우리는 숫자 데이터만 다뤘어요. 하지만 현실은 다릅니다.

    비유로 이해하기 텍스트 데이터는 마치 보물상자 안의 보물과 같아요. 상자를 열기 전에는 보이지 않지만, 체계적으로 열어보면 엄청난 정보가 담겨있습니다.

    정확한 정의 텍스트 데이터(Text Data)는 뉴스, 가사, SNS 글, 리뷰 등 언어로 표현된 정보를 말합니다. 이 정보들을 분석하면 어떤 단어가 자주 나타나는지, 사람들의 감정은 어떤지 파악할 수 있죠.

    예시로 확인 - 유튜브 노래 가사 100곡 분석 → "사랑", "꿈", "밤" 같은 단어 자주 등장 - 신문 기사 1000개 분석 → "경제", "정치", "기술" 중 어떤 주제가 많은가? - SNS 댓글 분석 → 사람들이 어떤 감정을 표현하는가?

    개념 2: 워드클라우드(Word Cloud)¶

    비유로 이해하기 워드클라우드는 마치 텍스트의 얼굴 사진과 같아요. 얼굴 사진을 보면 그 사람의 인상이 한눈에 들어오듯이, 워드클라우드를 보면 텍스트의 특징이 한눈에 보입니다.

    정확한 정의 워드클라우드는 텍스트에서 자주 나타나는 단어를 시각화한 그래프입니다. 자주 나타나는 단어일수록 더 크고 진하게 표시됩니다.

    예시로 확인 - BTS 가사로 만든 워드클라우드 → "사랑", "너", "밤" 이 크게 보임 - 코로나 관련 뉴스 분석 → "바이러스", "확진", "백신"이 크게 보임 - 당신의 영어 가사 분석 → 당신만의 특별한 시각적 작품 완성!

    개념 3: 왜 전공어로 해야 할까?¶

    비유로 이해하기 이것은 마치 당신의 언어 실력을 보여주는 포트폴리오를 만드는 것과 같습니다. 숫자만 다루는 데이터과학자가 되는 게 아니라, 언어 + 데이터의 전문가가 될 수 있다는 뜻이에요.

    🔨 따라하기¶

    Step 1: 워드클라우드 라이브러리 설치¶

    먼저 Python에 워드클라우드를 만드는 도구를 설치해야 합니다.

    코드: 

    # 터미널/명령프롬프트에 입력 (Python 실행 전에!)
pip install wordcloud matplotlib

    실행 결과: 설치 완료 메시지 출력

    Step 2: 기본 라이브러리 불러오기¶

    코드: 

    from wordcloud import WordCloud
import matplotlib.pyplot as plt

    Step 3: 텍스트 준비하기 (영어 예시)¶

    자신의 전공어 텍스트를 준비하세요. 영어 노래 가사를 예로 들겠습니다.

    코드: 

    # 당신이 좋아하는 노래 가사 또는 뉴스 기사를 여기에 붙여넣기
text = """
I have a dream that one day this nation will rise up
and live out the true meaning of its creed
We hold these truths to be self-evident
that all men are created equal
dream day nation rise truth meaning
"""

print("✅ 텍스트 준비 완료!")
print(f"총 단어 수: {len(text.split())}")

    실행 결과: 

    ✅ 텍스트 준비 완료!
총 단어 수: 28

    💡 팁: YouTube, 뉴스 사이트, 시 모음집에서 원하는 텍스트를 복사해 붙여넣으세요!

    Step 4: 워드클라우드 생성하기¶

    코드: 

    # 워드클라우드 객체 생성
wordcloud = WordCloud(
    width=800,           # 가로 크기
    height=600,          # 세로 크기
    background_color='white',  # 배경색
    font_path='C:/Windows/Fonts/arial.ttf',  # 영어 폰트
    max_words=100        # 최대 표시 단어 수
).generate(text)

print("✅ 워드클라우드 생성 완료!")

    실행 결과: 

    ✅ 워드클라우드 생성 완료!

    Step 5: 워드클라우드 시각화하기¶

    코드: 

    # 그래프 크기 설정
plt.figure(figsize=(12, 8))

# 워드클라우드 표시
plt.imshow(wordcloud, interpolation='bilinear')

# 축 제거 (더 깔끔하게)
plt.axis('off')

# 제목 추가
plt.title('내 전공어 Word Cloud 👏', fontsize=20, pad=20)

# 화면에 표시
plt.tight_layout(pad=0)
plt.show()

print("🎉 당신의 워드클라우드가 완성되었습니다!")

    실행 결과: 화면에 아름다운 워드클라우드가 나타납니다! 📊

    Step 6: 이미지로 저장하기 (선택사항)¶

    코드: 

    # PNG 파일로 저장
plt.figure(figsize=(12, 8))
plt.imshow(wordcloud, interpolation='bilinear')
plt.axis('off')
plt.title('내 전공어 Word Cloud 👏', fontsize=20, pad=20)
plt.tight_layout(pad=0)

# 저장
plt.savefig('my_wordcloud.png', dpi=300, bbox_inches='tight')
print("✅ my_wordcloud.png로 저장되었습니다!")
plt.show()

    📝 전체 코드¶

    from wordcloud import WordCloud
import matplotlib.pyplot as plt

# ==================== 1단계: 텍스트 준비 ====================
text = """
I have a dream that one day this nation will rise up
and live out the true meaning of its creed
We hold these truths to be self-evident
that all men are created equal
dream day nation rise truth meaning
"""

# ==================== 2단계: 워드클라우드 생성 ====================
wordcloud = WordCloud(
    width=800,
    height=600,
    background_color='white',
    font_path='C:/Windows/Fonts/arial.ttf',  # 영어 폰트
    max_words=100
).generate(text)

# ==================== 3단계: 시각화 ====================
plt.figure(figsize=(12, 8))
plt.imshow(wordcloud, interpolation='bilinear')
plt.axis('off')
plt.title('내 전공어 Word Cloud 👏', fontsize=20, pad=20)
plt.tight_layout(pad=0)
plt.show()

# ==================== 4단계: 저장 (선택) ====================
plt.savefig('my_wordcloud.png', dpi=300, bbox_inches='tight')
print("✅ 완성되었습니다! 친구들과 공유해보세요!")

    🌍 전공어별 팁¶

    영어 사용자 

    font_path='C:/Windows/Fonts/arial.ttf'

    중국어 사용자 

    font_path='C:/Windows/Fonts/simhei.ttf'  # Windows 기본 중국어 폰트

    일본어 사용자 

    font_path='C:/Windows/Fonts/meiryo.ttc'  # Windows 기본 일본어 폰트

    Mac 사용자 

    font_path='/System/Library/Fonts/Arial.ttf'

    ⚠️ 주의할 점¶

    1. 글꼴 경로 오류 날 때 - 경로를 정확히 입력했는지 확인하세요 - 한국 시스템이면 한글 폰트도 필요할 수 있습니다 - 불가능하면 font_path 줄을 삭제해도 됩니다 (기본 폰트 사용)

    2. 설치 오류 날 때 터미널에서 다시 한 번 입력하세요: 

    pip install --upgrade wordcloud matplotlib

    ✅ 점검하기¶

    1. 워드클라우드에서 가장 큰 글씨의 단어는 무엇인가요?

    답 확인 당신이 입력한 텍스트에서 **가장 자주 나타나는 단어**입니다. 이것이 그 텍스트의 핵심 주제를 나타냅니다!

    2. 내가 만든 워드클라우드와 친구 것과 다른 이유는?

    답 확인 서로 다른 텍스트를 사용했기 때문입니다. 같은 언어라도 어떤 텍스트를 선택하느냐에 따라 완전히 다른 시각적 모습이 됩니다!

    3. 데이터과학과 우리 전공어가 어떻게 연결되나요?

    답 확인 텍스트도 분석할 수 있는 데이터라는 사실! 여러분은 이제 **"숫자만 다루는 데이터과학자"가 아니라 "언어를 분석하는 데이터과학자"**가 될 수 있습니다. 국제 뉴스 분석, 해외 SNS 감정 분석, 다국어 트렌드 분석 등 무한한 가능성이 있어요! 🌍
