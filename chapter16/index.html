    Chapter 16. 분류 모델 만들기 - 붓꽃도 구분하고, 스팸도 걸러내고¶

    🎯 이 장에서 배우는 것¶

    • Orange3의 Tree 위젯으로 의사결정나무 모델을 만들 수 있다
    • 학습 데이터와 테스트 데이터를 분리해야 하는 이유를 이해한다
    • Test and Score 위젯으로 모델의 정확도를 측정하고 해석할 수 있다
    • Tree Viewer에서 모델의 의사결정 과정을 시각적으로 확인할 수 있다

    💡 왜 이걸 배우나요?¶

    혹시 이런 상황을 생각해본 적 있나요? 기말고사를 처음 본 학생이 만점을 받았다고 가정해봅시다.

    만약 선생님이 "이 학생은 대단해! 100점짜리 문제를 미리 주고 풀게 한 후, 같은 문제로 다시 시험을 봤더니 100점을 받았어"라고 한다면? 뭔가 이상하죠. 진짜 실력인지 알 수 없다는 뜻입니다.

    머신러닝도 똑같습니다. 모델을 학습할 때 쓴 같은 데이터로 성능을 평가하면 정확도가 부풀려집니다. 이번 장에서 배우는 학습-테스트 데이터 분리는 모델이 처음 보는 데이터에서 얼마나 잘하는지 진짜 실력을 재는 방법입니다.

    오늘은 붓꽃 데이터로 "꽃잎 길이와 너비만으로 붓꽃 종류를 맞힐 수 있을까?"라는 질문에 답해봅시다! 🌸

    📚 핵심 개념¶

    개념 1: 의사결정나무(Decision Tree) - 모델이 생각하는 방식¶

    비유: 동물을 분류하는 게임을 한다고 생각해봅시다. - "네 발인가?" → 아니오면 다음 질문으로 - "줄무늬가 있는가?" → 있으면 '호랑이', 없으면 '사자'

    의사결정나무는 이렇게 "예/아니오 질문을 반복"하면서 답을 찾아갑니다.

    정의: 데이터의 특성(feature)을 기준으로 계속 나누어가면서 가장 명확한 분류에 도달하는 모델입니다.

    예시: Iris 데이터에서 - "꽃잎 길이 < 2.5cm?" → Setosa - "꽃잎 길이 ≥ 2.5cm이고 너비 < 1.8cm?" → Versicolor - "그 외?" → Virginica

    이렇게 트리 모양으로 분류 규칙이 만들어집니다.

    개념 2: 학습-테스트 데이터 분리 - 공정한 평가의 원칙¶

    비유: 학생이 있습니다. - 학습 데이터(70%): 수학 문제집을 풀면서 배우는 과정 - 테스트 데이터(30%): 최종 시험에서 처음 보는 문제

    선생님이 "문제집에서 푼 같은 문제를 시험에 내고 채점했더니 95점"이라고 하면, 이건 이 학생의 진짜 실력이 아닙니다. 진짜 실력은 처음 보는 문제(테스트 데이터)에서 몇 점을 받는지로 판단해야 합니다.

    정의: 데이터를 두 부분으로 나누어 하나는 모델을 만들고(학습), 다른 하나로 모델 성능을 측정(평가)하는 방법입니다.

    예시: 150개의 붓꽃 데이터 - 학습: 105개 (70%) → 모델 생성 - 테스트: 45개 (30%) → 정확도 측정

    개념 3: 정확도(Accuracy) - 모델의 성적표¶

    비유: 날씨 예보자가 100일 동안 "내일 맑다/흐리다"를 예측했습니다. 실제로 78번 맞혔어요. 정확도 = 78% 입니다.

    정의: 전체 테스트 데이터 중에서 모델이 올바르게 분류한 비율

    $$\text{정확도} = \frac{\text{맞게 분류한 개수}}{\text{전체 데이터 개수}} \times 100\%$$

    예시: 테스트 데이터 45개 중 43개를 올바르게 분류 → 정확도 95.6%

    개념 4: 과적합(Overfitting) - 모델이 외우는 함정¶

    비유: 학생이 시험 문제집만 달달 외웠어요. 문제집 문제는 100점이지만, 처음 보는 문제는 50점입니다.

    정의: 모델이 학습 데이터에만 너무 잘 맞춰져서, 새로운 데이터에는 성능이 떨어지는 현상입니다.

    Orange3에서의 신호: 학습 정확도는 95%인데 테스트 정확도는 70%라면? → 과적합 의심!

    이를 방지하려면: - 학습-테스트 데이터를 분리해서 테스트 성능을 확인 - 트리의 깊이를 제한 (복잡도 낮추기)

    🔨 따라하기¶

    Step 1: Iris 데이터셋 불러오기¶

    Orange3를 열고 다음 순서로 진행합니다.

    위젯 배치: 1. File 위젯 추가 → Iris dataset 선택 2. Data Sampler 위젯 추가 → File과 연결

    왜 Data Sampler를 사용하나요? 학습 데이터(70%)와 테스트 데이터(30%)를 나누기 위해서입니다. 자동으로 70:30 비율로 분리해줍니다.

    File → Data Sampler

    Data Sampler를 더블클릭하면: - Proportion of data in sample: 70 (학습용) - Randomize: ✓ (체크, 매번 다른 데이터를 선택하지 않도록)

    Step 2: Tree 모델 생성하기¶

    위젯 추가: Tree 위젯을 추가하고 Data Sampler의 "Data Sample"(학습 데이터)과 연결합니다.

    Data Sampler (Data Sample) → Tree

    Tree 위젯을 더블클릭하면: - Splits: 10 (기본값, 나무가 최대 10개 깊이로 자라는 의미) - Min instances in leaf: 2 (각 잎사귀에 최소 2개 데이터)

    시작해봅시다!를 클릭하면 모델이 만들어집니다.

    Step 3: 모델의 의사결정 과정 확인하기¶

    위젯 추가: Tree Viewer 위젯을 추가하고 Tree와 연결합니다.

    Tree → Tree Viewer

    Tree Viewer를 더블클릭하면 나무 모양의 의사결정 규칙이 나타납니다:

    꽃잎 길이 < 2.45cm
├─ → Setosa (49개, 100%)
└─ 꽃잎 길이 ≥ 2.45cm
   ├─ 꽃잎 너비 < 1.75cm
   │  └─ → Versicolor (47개, 98%)
   └─ 꽃잎 너비 ≥ 1.75cm
      └─ → Virginica (9개, 100%)

    각 노드(동그라미)를 클릭하면 상세 정보를 볼 수 있어요!

    Step 4: 학습 정확도 확인¶

    위젯 추가: Confusion Matrix 위젯을 추가하고 Tree와 연결합니다.

    Tree → Confusion Matrix

    이 화면에서는 학습 데이터에 대한 정확도를 볼 수 있습니다. 보통 95% 이상으로 높게 나옵니다.

    Step 5: 테스트 정확도 확인 - 진짜 실력 측정!¶

    위젯 연결 추가: - Data Sampler의 "Data Remaining"(테스트 데이터) → Test and Score - Tree → Test and Score

    Tree ─→ Test and Score ←─ Data Sampler (Data Remaining)

    Test and Score를 더블클릭하면: - Evaluation results 탭에서 정확도 확인 - 일반적으로 학습 정확도보다 약간 낮게 나타남 (당연합니다!)

    예상 결과: 95~97% 정도의 정확도

    Step 6: 결과 비교하고 해석하기¶

    완성된 워크플로우는 이렇습니다:

    File (Iris) → Data Sampler → Tree → Test and Score
                           ↗   ↙
                     Tree Viewer &
                    Confusion Matrix

    비교 체크리스트: - ✓ Tree Viewer에서 "꽃잎 길이"가 첫 번째 기준인가? - ✓ 테스트 정확도가 90% 이상인가? - ✓ 학습 정확도와 테스트 정확도 차이가 5% 이내인가? (차이가 크면 과적합!)

    📝 전체 코드¶

    Orange3는 시각적 도구이기 때문에 "코드"가 없습니다. 하지만 Python으로 같은 작업을 하려면 이렇게 합니다:

    from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, confusion_matrix

# 1. 데이터 로드
iris = load_iris()
X = iris.data[:, 2:4]  # 꽃잎 길이, 너비만 사용
y = iris.target

# 2. 학습-테스트 데이터 분리
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

# 3. 의사결정나무 모델 생성
tree = DecisionTreeClassifier(max_depth=10, min_samples_leaf=2)
tree.fit(X_train, y_train)

# 4. 정확도 측정
train_accuracy = tree.score(X_train, y_train)
test_accuracy = tree.score(X_test, y_test)

print(f"학습 정확도: {train_accuracy:.1%}")
print(f"테스트 정확도: {test_accuracy:.1%}")

    실행 결과 예시: 

    학습 정확도: 96.2%
테스트 정확도: 95.6%

    ⚠️ 자주 하는 실수¶

    실수 1: Data Sampler 없이 같은 데이터로 학습과 평가하기¶

    ❌ 잘못된 방법: 

    File → Tree → Test and Score (같은 데이터 사용)
    결과: 정확도 98~99% (부풀려짐!)

    ✅ 올바른 방법: 

    File → Data Sampler → Tree → Test and Score
                   ↗        ↙

    실수 2: "테스트 정확도가 98%인데 왜 모든 데이터를 학습에 써요?"¶

    ❌ 생각: 더 많은 데이터로 배우면 더 좋지 않을까?

    ✅ 알아두기: - 확실히 더 좋은 모델이 될 수 있어요 - 하지만 성능을 공정하게 평가할 수 없습니다! - 실제 운영 환경에서 새로운 데이터가 들어올 때 얼마나 잘하는지 알 수 없어요

    실수 3: Tree Viewer에서 복잡한 나무가 나오면 "더 정교하다"고 생각하기¶

    ❌ 생각: 깊고 복잡한 나무 = 더 좋은 모델

    ✅ 알아두기: - 깊은 나무 = 학습 데이터에 과도하게 맞춰짐 - 테스트 정확도가 떨어질 가능성 ↑ - 실제로 운영할 때 새로운 데이터에서 성능 저하 가능

    해결책: Tree의 "Splits" 값을 줄여서 나무를 단순하게 만들어보세요!

    ✅ 스스로 점검하기¶

    이 항목들을 체크했으면 이번 장을 완벽하게 이해한 거예요:

    • Orange3에서 Data Sampler로 70:30 비율로 데이터를 분리할 수 있다
    • Tree 위젯으로 의사결정나무 모델을 만들었고, 모델이 어떤 순서로 질문하는지 Tree Viewer로 확인했다
    • 테스트 정확도가 학습 정확도보다 약간 낮은 이유를 설명할 수 있다
    • "왜 모든 데이터로 학습하고 모든 데이터로 평가하면 안 되는지"를 기말고사 비유로 설명할 수 있다
    • Confusion Matrix에서 어느 샘플이 잘못 분류되었는지 확인했다
