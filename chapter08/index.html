    Chapter 08. 수행평가 워크숍 ① - 아이디어 설계 & 데이터 수집¶

    🎯 이 장에서 배우는 것¶

    • 데이터 활용 아이디어를 A4 한 장 템플릿으로 정리할 수 있다
    • 공공데이터 포털에서 분석 주제에 맞는 데이터를 검색·다운로드할 수 있다
    • 수집한 데이터의 행·열 구조를 파악하고 설명할 수 있다
    • 자신의 아이디어와 데이터의 적합성을 검토할 수 있다

    💡 왜 이걸 배우나요?¶

    좋은 데이터 분석은 명확한 질문과 그에 맞는 데이터에서 시작됩니다.

    지금까지 우리는 "어떤 질문을 던져야 하는가"를 배웠습니다. 이제 "그 질문을 답하기 위해 어떤 데이터를 모아야 하는가"를 직접 실행해봅니다.

    이 장은 당신이 데이터 분석가처럼 움직이는 첫 번째 경험입니다: - 📋 아이디어를 다른 사람이 이해할 수 있게 정리하고 - 🔍 직접 데이터를 찾아다니며 - ✅ "이 데이터가 정말 내 질문에 답할 수 있나?" 스스로 판단하기

    📚 핵심 개념¶

    개념 1: 아이디어 설계 템플릿의 역할¶

    비유: 요리사가 요리를 만들기 전에 레시피를 쓰는 것처럼, 데이터 분석가도 분석을 시작하기 전에 분석 계획서를 작성합니다.

    정의: 아이디어 설계 템플릿은 분석 목적, 예상 데이터, 기대 결과를 간단히 정리한 문서입니다. 이것은: - 당신의 생각을 명확히 정렬하도록 강제합니다 - 다른 사람(선생님, 팀원)에게 당신의 계획을 설득합니다 - 분석 과정 중에 길을 잃지 않도록 나침반 역할을 합니다

    예시: "중고차 시장 가격 분석" 

    분석 목적: 차량 연식, 주행거리, 브랜드별로 
         중고차 가격이 어떻게 다른지 알아보기

예상 데이터: 공공데이터포털의 '자동차 거래 데이터' 
          (2023년 1월~12월)

기대 결과: 가격에 가장 큰 영향을 미치는 요소 파악 + 
         시각화(막대 그래프, 산점도)

    개념 2: 공공데이터포털의 데이터 구조 이해¶

    비유: 도서관의 "책 카드"를 생각해봅시다. 각 책은 제목, 저자, 출판사, ISBN 같은 정보를 가집니다. 데이터도 마찬가지로 체계적인 구조를 가집니다.

    정의: 공공데이터는 정부가 제공하는 행(row)과 열(column)로 이루어진 표 형태의 데이터입니다. - 행(row): 하나의 관찰 단위 (예: 1명의 학생, 1개의 학교, 1건의 거래) - 열(column): 변수 (예: 학생의 이름, 나이, 성적) - 셀(cell): 행과 열이 만나는 지점의 값

    예시: 학교 급식 데이터 

    행: 각 학교 (학교A, 학교B, 학교C, ...)
열: 학교명, 급식날짜, 메뉴, 칼로리, 식재료 산지

    개념 3: 데이터 수집의 3단계 (검색 → 선택 → 다운로드)¶

    비유: 슈퍼마켓에서 물건을 사는 과정입니다. 먼저 필요한 물건을 찾고(검색), 여러 브랜드 중 가장 좋은 것을 선택(선택), 마지막으로 레지에서 계산(다운로드)합니다.

    정의: 공공데이터포털에서 데이터를 가져오는 3단계 프로세스입니다:

    1️⃣ 검색 단계: 키워드로 데이터셋 찾기 (예: "학교", "인구") 2️⃣ 선택 단계: 설명(메타데이터)를 읽고 자신의 목적과 맞는지 확인 3️⃣ 다운로드 단계: CSV, Excel, JSON 등 형식으로 내 컴퓨터에 저장

    예시: "서울시 자전거 도로 데이터" 다운로드 

    1️⃣ 포털 검색창에 "자전거 도로" 입력
2️⃣ 검색 결과 중 "서울시 자전거 도로 현황(2024)" 클릭
   → 설명 읽기: "구별 자전거 도로 길이, 설치년도 포함"
   → "맞다! 이거 써야겠다" 결정
3️⃣ "다운로드" 버튼 클릭 → CSV 선택 → 저장

    개념 4: 데이터 적합성 검증¶

    비유: 요리 레시피가 정해졌는데 재료가 없으면 요리할 수 없습니다. 마찬가지로 아이디어는 좋아도 필요한 데이터가 없으면 분석을 시작할 수 없습니다.

    정의: 수집한 데이터가 실제로 당신의 분석 목적을 달성할 수 있는지 확인하는 과정입니다.

    검증 체크리스트: - ✓ 분석 주제와 관련된 변수가 있는가? - ✓ 데이터 개수가 충분한가? (최소 30행 이상 권장) - ✓ 데이터가 최신인가? (2년 이내 업데이트) - ✓ 빠진 데이터(결측치)가 많지 않은가? - ✓ 이해 불가능한 코드나 약자는 없는가? (설명 문서 필요)

    안 좋은 예 👎: - "세상의 모든 것 분석" (너무 광범위) - "행복도" (데이터로 측정하기 모호) - "미래 예측" (지금 단계에서는 난이도가 높음)

□ 주제와 관련성 있는가?
□ 제공 기관이 공식기관인가? (시청, 통계청, 교육청 등)
□ 최신 데이터인가? (1~2년 이내 업데이트)
□ 데이터 설명(메타데이터)이 충분한가?
□ 행 개수가 30개 이상인가?
─────────────────────────────────

총점: ____ / 5점 (4점 이상이면 OK!)

    📊 수집 데이터 정보

데이터명: 서울시 소상공인 개·폐업 현황 (2021~2024)

행의 개수: 347개
열의 개수: 8개

각 열의 이름과 의미:
• 가게명(텍스트): 소상공인의 이름
• 개업일(날짜): YYYY.MM 형식
• 폐업일(날짜): 폐업하지 않은 경우 공란
• 소재지(텍스트): 행정동 단위
• 업종(텍스트): 카페, 음식점, 미용실 등

데이터 품질 평가:
- 결측치 비율: 약 15% (비고 열)
- 데이터 최신성: 좋음 ✓
- 분석 적합성: 우수 ✓

    ⚠️ 자주 하는 실수¶

    실수 1: 주제가 너무 광범위해서 데이터를 못 찾는 경우¶

    ❌ 문제 상황: 

    분석 주제: "한국 사회의 문제점을 데이터로 분석"
→ 너무 넓다! 데이터 검색이 막힌다.

    ✅ 해결 방법: 

    분석 주제: "서울시 25~34세 1인가구의 월평균 생활비 변화"
→ 구체적이면 데이터도 찾기 쉽다!

    핵심: 지역, 시간, 대상, 항목을 명시하세요.

    실수 2: 데이터는 찾았는데 구조를 못 파악하는 경우¶

    ❌ 문제 상황: 

    "Excel 파일을 열었는데 무게 많은 데이터고 
어떤 열이 뭔지 모르겠어요..."

    ✅ 해결 방법: 

    1. 맨 첫 행을 꼭 읽기 (변수명이 있음)
2. 맨 아래 5~10행 샘플 데이터 읽기
3. "이 열은 언제 사용할 거야?" 생각하기
4. 데이터 설명 문서(.pdf) 함께 다운로드하기

    실수 3: 결측치(빈칸)가 많아서 분석 불가능한 데이터 선택¶

    ❌ 문제 상황: 

    다운로드한 데이터를 보니 60% 이상의 셀이 비어있음
→ "이 데이터로는 분석을 못 하겠는데?"

    ✅ 해결 방법: 

    다운로드 전에 미리보기로 확인:
1. 포털 사이트에서 "데이터 조회" 클릭
2. 처음 50행을 미리본다
3. 빈칸 비율 추정 (20% 이상이면 위험)
4. 다른 데이터셋 찾아보기

    기준: 한 열에 30% 이상의 빈칸이 있으면 피하세요.

□ 공공데이터포털에서 다운로드함
□ 데이터가 CSV 형식임
□ 파일명이 명확함 (예: 2024_주제_지역.csv)

데이터 구조 파악

□ 데이터 타입(텍스트, 숫자, 날짜)을 분류함
□ 결측치 여부를 확인함
□ 분석 적합성을 자체 평가함 (적절함/부적절함)
