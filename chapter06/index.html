    Chapter 6. 데이터는 어디에? - 공공데이터의 세계¶

    🎯 이 장에서 배우는 것¶

    • 공공데이터 포털에서 내 관심사의 데이터를 검색할 수 있다
    • CSV와 Excel 파일의 차이를 설명하고 각각을 열어볼 수 있다
    • 데이터의 신뢰성을 판단하는 3가지 기준을 적용할 수 있다
    • 한국의 주요 공공데이터 출처 3곳 이상을 나열할 수 있다

    💡 왜 이걸 배우나요?¶

    지금까지 우리는 "데이터란 무엇인가"를 배웠어요. 이제 물어야 할 질문은 "그럼 데이터는 어디 있나?"입니다.

    혼자 조사하는 학생 프로젝트든, 회사의 마케팅 분석이든 모든 데이터 분석은 "좋은 데이터를 찾는 것"에서 시작돼요. 마치 요리사가 신선한 재료를 찾으러 시장에 가듯이, 데이터 분석가는 신뢰할 수 있는 데이터를 찾으러 떠나야 하거든요.

    다행히 한국은 "공공데이터"라는 보물 창고를 국민에게 무료로 공개하고 있어요. 이 장에서는 그 보물을 찾는 방법을 배워봅시다.

    📚 핵심 개념¶

    개념 1: 공공데이터란 무엇인가?¶

    비유: 공공도서관처럼, 누구나 와서 꺼내갈 수 있는 데이터 도서관입니다.

    정의: 정부와 공공기관이 만들고 관리하는 데이터 중에서 누구나 자유롭게 다운로드하고 사용할 수 있도록 공개한 정보입니다.

    구체적 예시 - 🏘️ 서울시의 맛집 위치와 위생 등급 - 📊 통계청의 월별 실업률 통계 - 🏥 보건소별 예방접종 현황 - 📚 도서관의 도서 보유 현황 - 🚗 교통량 및 주차장 정보

    왜 공개할까? 세금으로 만들어진 데이터니까, 국민이 활용하도록 하는 게 맞다는 철학이에요.

    개념 2: 공공데이터의 주요 출처 3곳¶

    data.go.kr (공공데이터 포털) - 한국의 중앙정부 데이터 집결지 - 약 45,000개 이상의 데이터셋 보유 - 가장 먼저 방문해야 할 곳

    KOSIS (국가통계포털) - 통계청이 만든 공식 통계 전용 플랫폼 - 경제, 사회, 인구 관련 신뢰도 높은 데이터 - 시계열(시간에 따른 변화) 데이터가 풍부

    서울열린데이터광장 (https://data.seoul.go.kr) - 서울시의 지역 데이터 특화 - 각 자치구마다 유사한 사이트 있음 - 생활밀착형 데이터 (버스, 지하철, 맛집 등)

    개념 3: 파일 형식 - CSV vs Excel¶

    CSV (Comma-Separated Values) 

    이름,나이,도시,직업
김철수,28,서울,개발자
이영희,25,대전,디자이너
박준호,30,부산,마케터

    특징: - 순수 텍스트 형식 (메모장으로도 열 수 있음) - 모든 프로그램에서 호환 (Python, Excel, Google Sheets 모두 OK) - 용량이 작음 - 꾸미기 기능이 없음 (색상, 글꼴 등 불가)

    Excel (.xlsx) - Microsoft가 만든 스프레드시트 형식 - 그래프, 함수, 여러 시트 포함 가능 - 용량이 더 크지만 기능이 더 풍부함

    어떤 걸 다운받아야 할까? - 파이썬으로 분석할 거면? → CSV 추천 (가볍고 호환성 좋음) - 엑셀에서 바로 분석할 거면? → Excel 또는 CSV 둘 다 OK - 의심스러우면? → CSV 선택 (거의 모든 도구가 지원)

    개념 4: 데이터 신뢰성 판단하기¶

    데이터도 "출처 확인"이 중요해요. 신문 기사를 읽을 때 어느 신문사에서 나온 기사인지 확인하듯이요.

    신뢰성 체크리스트 (3가지 필수)

    1️⃣ 출처 확인: 누가 만들었나? - ✅ 좋음: 통계청, 시청, 보건복지부 같은 정부기관 - ❌ 의심: "출처 미상", "인터넷 어딘가", 개인 블로그

    2️⃣ 최신성 확인: 언제 업데이트됐나? - ✅ 좋음: 작년, 올해 데이터 (갱신 주기가 명시됨) - ❌ 의심: 5년 전 데이터, 업데이트 날짜 불명확

    3️⃣ 설명 확인: 데이터가 뭔지 알 수 있나? - ✅ 좋음: "각 변수의 의미" (메타데이터)가 설명되어 있음 - ❌ 의심: 숫자만 있고 뭘 의미하는지 모름

    🔨 따라하기¶

    Step 1: data.go.kr에 접속하기¶

    1. 웹브라우저를 열고 data.go.kr로 이동해요
    2. 화면이 로드되면 상단의 검색창을 찾아요

    ![공공데이터 포털 홈페이지]

    Step 2: 관심사로 데이터 검색하기¶

    예제로 "대전 맛집"을 검색해볼게요. (자신의 관심사로 바꿔도 돼요!)

    1. 검색창에 "대전 식당" 또는 "음식점" 입력
    2. 검색 버튼 클릭

    검색 팁 - 너무 구체적으로? → 결과 없을 수 있음 ("강남역 8번출구 한식당" ✗) - 적당한 수준으로 → ("식당", "음식점", "대전") ✓

    결과 화면에서 여러 데이터셋이 나타나요. 각 항목을 클릭하면 상세 정보를 볼 수 있습니다.

    Step 3: 데이터셋 상세 보기¶

    마음에 드는 데이터를 하나 선택해요. 보통 이런 정보가 있습니다:

    • 제목: 데이터의 이름
    • 설명: 데이터가 뭔지 설명
    • 제공 기관: 누가 만들었나
    • 최종 수정일: 언제 업데이트됐나
    • 데이터 포맷: CSV, Excel, JSON 등

    신뢰성 체크: 제공 기관이 공식 정부기관인지 확인하세요!

    Step 4: 파일 다운로드하기¶

    상세 페이지에서 "다운로드" 버튼을 찾아요.

    파일명: 대전음식점목록_202401.csv
크기: 256 KB
형식: CSV

    위 같은 정보가 보이면, 파일을 클릭해 다운로드합니다. 브라우저 아래쪽에 파일이 내려오는 게 보여요.

    Step 5: 다운로드한 파일 열어보기¶

    CSV 파일 열기: 1. 다운로드 폴더에서 파일을 찾아요 2. 더블클릭 → 엑셀이나 Google Sheets가 자동으로 열림 3. 데이터가 표 형식으로 나타나요!

    구조 확인 

    첫 행(헤더): 이름, 주소, 전화, 위생등급, ...
2번째 행부터: 실제 데이터들

    "이게 뭐하는 데이터지?" 싶을 때: - data.go.kr에서 해당 페이지로 돌아가기 - "데이터 설명서" 또는 "메타데이터" 탭 확인 - 각 칼럼(열)이 뭘 의미하는지 설명되어 있어요

    Step 6: 다른 출처도 찾아보기¶

    한 곳에서 안 나오면 다른 곳을 시도해봐요:

    🔍 "외국어 관련 취업 통계" 찾기 - KOSIS (kosis.kr) → "취업통계" 검색 - 워크넷 (worknet.go.kr) → 직업정보 탭

    🔍 "서울 버스 노선" 찾기 - 서울열린데이터광장 → "대중교통" 검색 - data.go.kr → "서울교통" 검색

    각 출처마다 데이터 질과 형식이 다르니까, 여러 출처에서 비교해보는 것도 좋은 습관이에요.

    📝 검색 연습지¶

    이 템플릿을 따라 자신의 관심 데이터를 찾아보세요:

    주제: ________________

1. 어느 포털에서 찾았나?
   □ data.go.kr  □ KOSIS  □ 지역 포털  □ 기타: ________

2. 데이터 이름: ________________

3. 제공 기관: ________________

4. 최종 수정일: ________________

5. 신뢰성 점수 (⭐⭐⭐⭐⭐ 중 선택):
   - 출처: ⭐⭐⭐⭐⭐
   - 최신성: ⭐⭐⭐⭐⭐
   - 설명: ⭐⭐⭐⭐⭐

6. 첫 인상: 이 데이터로 뭘 할 수 있을까?
   ________________

    ⚠️ 자주 하는 실수¶

    ❌ 실수 1: "가장 많은 다운로드 수 = 가장 좋은 데이터" 라고 생각하기

    data.go.kr에서는 다운로드 수 순으로 정렬할 수 있어요. 하지만 인기 많은 데이터가 항상 최신이거나 정확한 건 아니에요. 직접 메타데이터를 읽어보세요.

    ✅ 올바른 방법: 다운로드 수보다는 "최종 수정일"과 "설명의 상세함"을 우선으로 봐요.

    ❌ 실수 2: Excel만 쓸 거라면서 이상한 CSV 파일 다운받기

    CSV로 받은 파일을 엑셀에서 열면 인코딩 문제로 한글이 깨질 수 있어요 (특히 Windows에서).

    ✅ 올바른 방법: - Excel 파일이 있으면 Excel로 다운받기 - CSV밖에 없으면, 엑셀에서 "다른 이름으로 저장 → CSV → 인코딩: UTF-8" 설정

    ❌ 실수 3: "이 데이터는 정부 사이트니까 100% 정확하겠지" 라고 생각하기

    공공데이터도 입력 오류, 오래된 정보가 있을 수 있어요.

    ✅ 올바른 방법: - 최소 2개 이상의 출처에서 같은 데이터 확인하기 - 데이터에 의문이 있으면 제공 기관에 문의하기 - 일부 데이터만 샘플로 확인해본 후 다운로드하기

    ✅ 스스로 점검하기¶

    각 질문에 "네"라고 답할 수 있으면 이 장을 이해한 거예요:

    1. data.go.kr에 가면 어떤 종류의 데이터를 찾을 수 있을까요?

    2. 정부기관이 공개하는 모든 종류의 데이터

    3. CSV 파일과 Excel 파일의 가장 큰 차이는?

    4. CSV는 순수 텍스트, Excel은 꾸미기 기능 포함 + 파이썬과 호환성은 CSV가 더 좋음

    5. "신뢰할 수 있는 데이터"의 3가지 판단 기준은?

    6. 출처(누가), 최신성(언제), 설명(뭔지)

    7. KOSIS와 data.go.kr의 차이는?

    8. KOSIS는 통계 특화, data.go.kr은 모든 공공데이터 종합

    9. 내 지역의 데이터는 어디서 찾을까?

    10. 각 시·도 열린데이터광장 (예: 서울열린데이터광장)

    🚀 더 해보기¶

    도전 1: 3가지 다른 출처에서 같은 주제의 데이터 찾기

    예: "대전시 인구 통계" - data.go.kr에서 찾기 - KOSIS에서 찾기 - 대전시 공식 홈페이지에서 찾기

    → 세 곳의 데이터가 같은가? 다른가? 왜 다를까?

    도전 2: 메타데이터 읽고 변수 이해하기

    다운받은 CSV를 열었는데 "code_nm", "std_month" 같은 낯선 이름이 있다면: - data.go.kr의 "설명서" 탭을 찾기 - 각 열(칼럼)이 정확히 뭘 의미하는지 메모하기

    → 이게 진짜 데이터 분석의 첫 단계예요!

    도전 3: 가장 "신뢰도 높은" 데이터 10개 리스트 만들기

    data.go.kr에서: 1. 10개의 데이터를 검색해보기 2. 각각의 출처, 최신성, 설명 수준을 평가하기 3. 별점 5개 중 4개 이상인 것들만 모으기

    → 나만의 "데이터 신뢰도 가이드"가 만들어져요!
