    🎯 이 장에서 배우는 것¶

    • 데이터 수집부터 모델링까지 데이터과학의 6단계 여정을 설명할 수 있다
    • 파이썬(Pandas)과 Orange3의 역할 차이를 구분할 수 있다
    • Google Colab의 기본 인터페이스를 확인하고 첫 코드를 실행할 수 있다

    📚 핵심 개념¶

    개념 1: 데이터과학의 6단계 여행¶

    비유: 데이터과학은 마치 보물찾기와 같아요. 보물지도(데이터 수집) → 지도 읽기(전처리) → 지형 확인(시각화) → 패턴 발견(탐색분석) → 예측 모델 만들기(머신러닝) → 결과 공유(프레젠테이션)까지 차근차근 진행합니다.

    정의: 데이터과학은 현실의 복잡한 데이터를 정리하고, 의미 있는 패턴을 찾아 미래를 예측하는 과정입니다. 6단계를 거칩니다:

    1. 수집(Collection): 실제 데이터를 모아요
    2. 전처리(Preprocessing): 지저분한 데이터를 깨끗하게 정리해요
    3. 시각화(Visualization): 그래프와 차트로 데이터를 그려요
    4. 탐색분석(EDA): 데이터 안의 숨겨진 패턴을 찾아요
    5. 모델링(Modeling): 미래를 예측하는 AI 모델을 만들어요
    6. 공유(Communication): 발견한 내용을 다른 사람에게 설명해요

    예시: 영화 평점 데이터로 생각해보세요. - 수집: 100만 개의 영화 평점 데이터 다운로드 - 전처리: 오류나 누락된 데이터 제거 - 시각화: 장르별 평점을 막대그래프로 표현 - 탐색분석: "액션영화가 코미디영화보다 평점이 높네?"라는 발견 - 모델링: "이 영화의 내용으로 평점을 예측해주는 모델" 제작 - 공유: "우리 모델은 80% 정확도를 가집니다"라고 발표

    개념 2: 파이썬 vs Orange3 - 도구의 역할 구분¶

    비유: 파이썬은 "요리사가 직접 칼질하며 요리하는 것", Orange3는 "요리로봇 버튼만 누르는 것"이라고 생각하세요.

    정의:

    파이썬 (손으로 직접) - 코드를 타이핑하며 데이터를 정확하게 제어 - 유연함: 원하는 대로 커스터마이징 가능 - 배우는 데 시간이 걸리지만, 배우면 가장 강력함 - 이 수업의 실습자료들은 이미 완성된 코드로 제공됨

    Orange3 (드래그앤드롭) - 마우스로 블록을 연결하기만 해도 동작 - 빠름: 즉시 결과를 볼 수 있음 - 코딩을 몰라도 머신러닝의 전체 과정을 경험 - 직관적이지만, 세밀한 조정은 제한적

    graph TB subgraph Python["🐍 파이썬 (텍스트 코딩)"] P1["코드 작성<br/>import pandas"] P2["한 줄씩<br/>실행"] P3["자세한<br/>제어 가능"] end subgraph Orange["🟠 Orange3 (시각적 프로그래밍)"] O1["블록을<br/>드래그"] O2["연결만<br/>하기"] O3["즉시<br/>결과 확인"] end style Python fill:#fff9c4 style Orange fill:#ffccbc

    사용 전략: - 처음 배울 때: Orange3로 전체 과정을 빠르게 이해 - 깊이 있게 배울 때: 파이썬으로 각 단계를 정확하게 제어

    개념 3: Google Colab - 클라우드 파이썬 실험실¶

    비유: Google Colab은 마치 "집에 구비할 필요 없는 공용 실험실"이에요. 로그인만 하면 파이썬 환경이 바로 준비됩니다.

    정의: Google Colab(구글 코랩)은 구글에서 무료로 제공하는 클라우드 기반 파이썬 작업 환경입니다.

    장점: - 💻 설치 불필요: 웹브라우저만 있으면 됨 - 🆓 무료: 구글 계정이 있으면 OK - ⚡ 빠름: 서버가 자동으로 준비됨 - 📁 저장: 구글 드라이브에 자동 저장

    🔨 따라하기¶

    Step 1: Google Colab 접속하기¶

    행동: 1. 웹브라우저를 열어요 (크롬 추천) 2. 주소창에 colab.research.google.com 입력 3. 구글 계정으로 로그인

    Step 2: 새 노트북 만들기¶

    접속 후 화면에 보이는 "+ 새 노트북" 버튼 클릭하세요.

    Step 3: 첫 코드 작성하기¶

    화면의 첫 번째 셀(회색 박스)을 클릭하고 아래를 입력하세요:

    # 우리의 첫 번째 데이터과학 명령어
print("안녕하세요! 저는 데이터과학자입니다!")

    Step 4: 코드 실행하기¶

    방법 A: 셀 왼쪽의 ▶ 재생 버튼 클릭
    방법 B: 키보드에서 Ctrl + Enter 누르기

    실행 결과: 

    안녕하세요! 저는 데이터과학자입니다!

    Step 5: 파이썬 기본 명령어 체험¶

    같은 방식으로 아래를 실행해보세요:

    # 간단한 계산
숫자들 = [10, 20, 30, 40, 50]
평균 = sum(숫자들) / len(숫자들)
print(f"평균: {평균}")

    실행 결과: 

    평균: 30.0

    Step 6: 파일 저장하기¶

    화면 왼쪽 위 파일 아이콘 → "드라이브에 사본 저장" 클릭
    → 구글 드라이브에 자동으로 저장됩니다

    📝 전체 코드¶

    # 📊 우리의 첫 번째 데이터과학 여행

# 1단계: 간단한 데이터 준비 (수집)
영화이름 = ["아바타", "타이타닉", "어벤져스"]
평점 = [8.5, 8.9, 8.4]

# 2단계: 평균 구하기 (탐색분석)
평균평점 = sum(평점) / len(평점)
print(f"모든 영화의 평균 평점: {평균평점:.1f}점")

# 3단계: 최고 평점 찾기
최고점수 = max(평점)
최고영화 = 영화이름[평점.index(최고점수)]
print(f"최고 평점 영화: {최고영화} ({최고점수}점)")

# 4단계: 결과 정리 (공유)
print("\n📈 우리의 첫 데이터 분석 완료!")

    실행 결과: 

    모든 영화의 평균 평점: 8.6점
최고 평점 영화: 타이타닉 (8.9점)

    2. 셀 실행 순서가 중요해요 - 위에서 아래로 차례대로 실행하세요 - 건너뛰면 오류가 날 수 있습니다

    ✅ 점검하기¶

    1. 데이터과학의 6단계를 순서대로 나열해보세요.

    정답 확인 수집 → 전처리 → 시각화 → 탐색분석 → 모델링 → 공유 이 순서대로 배워나갈 거예요!

    2. 파이썬과 Orange3의 가장 큰 차이는 무엇인가요?

    정답 확인 **파이썬**: 코드를 직접 타이핑하며 세밀하게 제어 (유연함, 강력함) **Orange3**: 블록을 드래그하며 빠르게 결과 확인 (직관적, 빠름) 둘 다 똑같이 중요한 도구입니다!

    3. Google Colab에 접속해서 간단한 코드를 실행했나요?

    정답 확인 ✅ 네! 성공했다면 이제 당신은 클라우드 기반 데이터과학자입니다 🎉 처음 실행이 안 되면 선생님께 질문해도 괜찮습니다.
