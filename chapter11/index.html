    Chapter 11: 데이터를 그림으로 - 시각화의 힘¶

    🎯 이 장에서 배우는 것¶

    • matplotlib으로 기본 그래프(막대, 선, 산점도)를 그릴 수 있다
    • 데이터 특성에 맞는 그래프 유형을 선택할 수 있다
    • 제목, 라벨, 색상으로 그래프의 가독성을 높일 수 있다
    • seaborn으로 더 예쁜 그래프를 만들 수 있다

    💡 왜 이걸 배우나요?¶

    상황을 상상해보세요.

    동료가 당신에게 엑셀 파일을 건넸습니다. "지난 3개월 매출 데이터야." 숫자가 2,000개 있습니다. 당신은 이 데이터에서 뭘 할 수 있을까요?

    • 숫자 2,000개를 읽고 분석? 🥵 불가능합니다.
    • 같은 데이터를 그래프로 보여주기? 📊 한눈에 이해됩니다!

    수치 vs 시각화 - 숫자: "1월 매출 3,200만 원, 2월 3,450만 원..." - 그래프: "아, 계속 올라가고 있네!" ← 1초에 이해

    데이터 분석가가 되려면 숫자를 말로 전할 수 없습니다. 반드시 그림으로 보여줘야 합니다. 그리고 그 그림을 파이썬으로 그리는 방법이 바로 이 장의 목표입니다.

    📚 핵심 개념¶

    개념 1: 시각화란?¶

    숫자를 그림으로 번역하는 과정

    데이터를 표(table)로 표현하면 정확하지만 읽기 힘듭니다. 하지만 그래프로 표현하면 인간의 뇌가 패턴을 빠르게 인식합니다.

    숫자: 100, 150, 120, 200, 180
     ↓
그래프:  📈 (상승 추세? 변동성? 한눈에 안 보이죠?)

    왜 효과적일까?

    인간의 뇌는 이미지 처리 능력이 문자의 60,000배입니다. 따라서: - 수치 데이터 → 선 그래프(추세 파악) - 카테고리별 비교 → 막대 그래프(크기 비교) - 두 변수 관계 → 산점도(상관관계 파악)

    개념 2: matplotlib이 뭔가요?¶

    파이썬의 가장 기본적인 시각화 라이브러리

    matplotlib은 "저수준" 라이브러리입니다. 즉, 세세한 조정이 가능하지만 코드가 조금 깁니다. 하지만 가장 널리 쓰이고, 다른 라이브러리의 기초가 됩니다.

    import matplotlib.pyplot as plt  # 이 한 줄로 시작

    개념 3: seaborn은 matplotlib의 친구¶

    matplotlib을 더 예쁘게 포장한 라이브러리

    matplotlib은 기능은 많지만 기본 스타일이 밋밋합니다. seaborn은 matplotlib 위에 얹어서 더 현대적이고 예쁜 그래프를 만듭니다.

    생각해보면: - matplotlib = 레고 벽돌(기본 재료) - seaborn = 미리 만들어진 레고 세트(편하고 예쁨)

    개념 4: 그래프 선택 기준¶

    graph TD A["데이터를 어떻게 표현할까?"] --> B["카테고리별로 비교?"] A --> C["시간 변화를 보고 싶어?"] A --> D["두 변수의 관계?"] B --> E["막대 그래프<br/>Bar Chart"] C --> F["선 그래프<br/>Line Chart"] D --> G["산점도<br/>Scatter Plot"] style E fill:#ffe6e6 style F fill:#e6f3ff style G fill:#e6ffe6

    🔨 따라하기¶

    사전 준비¶

    먼저 필요한 라이브러리를 설치하세요.

    pip install matplotlib seaborn pandas

    Step 1: 간단한 데이터 만들기¶

    import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns

# 가짜 매출 데이터 (3개월)
months = ['1월', '2월', '3월']
sales = [100, 150, 120]

print("데이터:")
print(f"월: {months}")
print(f"매출: {sales}")

    출력: 

    데이터:
월: ['1월', '2월', '3월']
매출: [100, 150, 120]

    Step 2: 막대 그래프 그리기¶

    # 새 그래프 창 만들기
plt.figure(figsize=(8, 5))

# 막대 그래프 그리기
plt.bar(months, sales, color='skyblue', edgecolor='navy')

# 제목과 축 라벨 추가
plt.title('월별 매출액', fontsize=16, fontweight='bold')
plt.xlabel('월', fontsize=12)
plt.ylabel('매출(만원)', fontsize=12)

# 격자 추가 (읽기 편함)
plt.grid(axis='y', alpha=0.3)

plt.tight_layout()
plt.show()

    그래프 해석: - 1월 매출은 100만원 - 2월에 50만원 증가했다는 것을 바로 알 수 있습니다 - 3월에 다시 떨어졌습니다

    Step 3: 선 그래프 그리기¶

    # 같은 데이터, 다른 관점
plt.figure(figsize=(8, 5))

plt.plot(months, sales, marker='o', linewidth=2, markersize=8, color='red')

plt.title('월별 매출 추세', fontsize=16, fontweight='bold')
plt.xlabel('월', fontsize=12)
plt.ylabel('매출(만원)', fontsize=12)
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

    '똑같은 데이터, 다른 보임새' - 막대 그래프: "각 달의 절대값 비교"에 좋음 - 선 그래프: "시간에 따른 변화 추세"를 더 직관적으로 보여줌

    Step 4: 산점도 그리기 (2개 변수 관계)¶

    # 광고비 vs 매출 데이터
ad_cost = [10, 20, 15, 25, 30]  # 광고비(만원)
revenue = [50, 120, 80, 150, 180]  # 매출(만원)

plt.figure(figsize=(8, 5))

# 산점도 그리기
plt.scatter(ad_cost, revenue, s=100, alpha=0.6, color='green')

plt.title('광고비와 매출의 관계', fontsize=16, fontweight='bold')
plt.xlabel('광고비(만원)', fontsize=12)
plt.ylabel('매출(만원)', fontsize=12)
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

    질문: 광고비가 많을수록 매출이 늘어날까? → 그래프로 한눈에 답이 보입니다!

    Step 5: seaborn으로 더 예쁘게¶

    # seaborn 스타일 설정 (한번만 하면 됨)
sns.set_style("whitegrid")
sns.set_palette("husl")

# DataFrame으로 데이터 정리
df = pd.DataFrame({
    '월': ['1월', '2월', '3월', '4월'],
    '매출': [100, 150, 120, 180],
    '비용': [40, 50, 45, 60]
})

# 그룹별 막대 그래프
fig, ax = plt.subplots(figsize=(10, 6))
x_pos = range(len(df))
width = 0.35

ax.bar([p - width/2 for p in x_pos], df['매출'], width, label='매출', color='#FF6B6B')
ax.bar([p + width/2 for p in x_pos], df['비용'], width, label='비용', color='#4ECDC4')

ax.set_xlabel('월', fontsize=12)
ax.set_ylabel('금액(만원)', fontsize=12)
ax.set_title('월별 매출과 비용 비교', fontsize=14, fontweight='bold')
ax.set_xticks(x_pos)
ax.set_xticklabels(df['월'])
ax.legend()
ax.grid(axis='y', alpha=0.3)

plt.tight_layout()
plt.show()

    Step 6: 색상 커스터마이징 (내 스타일 만들기)¶

    # 색상 변경 예시
colors = ['#FF6B6B', '#4ECDC4', '#45B7D1', '#FFA07A']

plt.figure(figsize=(8, 5))
plt.bar(df['월'], df['매출'], color=colors)

plt.title('내 스타일의 그래프 🎨', fontsize=16, fontweight='bold')
plt.xlabel('월', fontsize=12)
plt.ylabel('매출(만원)', fontsize=12)

plt.tight_layout()
plt.show()

    📝 전체 코드¶

    한 파일에 모두 담은 완전 코드:

    import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns

# 한글 폰트 설정 (필요시)
plt.rcParams['font.family'] = 'DejaVu Sans'

# 1. 기본 데이터
months = ['Jan', 'Feb', 'Mar']
sales = [100, 150, 120]

# 2. 막대 그래프
plt.figure(figsize=(10, 5))
plt.subplot(1, 3, 1)
plt.bar(months, sales, color='skyblue')
plt.title('Bar Chart')
plt.ylabel('Sales')

# 3. 선 그래프
plt.subplot(1, 3, 2)
plt.plot(months, sales, marker='o', color='red')
plt.title('Line Chart')
plt.ylabel('Sales')

# 4. 산점도
ad_cost = [10, 20, 15, 25, 30]
revenue = [50, 120, 80, 150, 180]
plt.subplot(1, 3, 3)
plt.scatter(ad_cost, revenue, color='green')
plt.title('Scatter Plot')
plt.xlabel('Ad Cost')
plt.ylabel('Revenue')

plt.tight_layout()
plt.show()

# 5. seaborn 예제
sns.set_style("whitegrid")
df = pd.DataFrame({
    'Month': ['Jan', 'Feb', 'Mar', 'Apr'],
    'Sales': [100, 150, 120, 180]
})

plt.figure(figsize=(8, 5))
sns.barplot(data=df, x='Month', y='Sales', palette='Set2')
plt.title('Monthly Sales with Seaborn', fontweight='bold')
plt.show()

    ⚠️ 자주 하는 실수¶

    실수 1: 한글이 깨져서 나타나요¶

    문제: 

    plt.title('월별 매출')  # ㄱㄱㄱ처럼 깨짐

    해결: 

    plt.rcParams['font.family'] = 'DejaVu Sans'  # 영문 사용
# 또는
plt.rcParams['font.family'] = 'Noto Sans CJK KR'  # 한글 지원 폰트

    실수 2: plt.show()를 안 했는데 그래프가 안 떠요¶

    문제: 

    plt.bar(months, sales)
plt.title('제목')
# 여기서 끝내면 화면에 안 떠요!

    해결: 

    plt.bar(months, sales)
plt.title('제목')
plt.show()  # 필수!

    실수 3: 데이터 길이가 안 맞습니다¶

    문제: 

    months = ['Jan', 'Feb', 'Mar']
sales = [100, 150]  # 개수가 안 맞음!
plt.bar(months, sales)  # 에러 발생

    해결: 

    months = ['Jan', 'Feb', 'Mar']
sales = [100, 150, 120]  # 개수 맞춰주기
plt.bar(months, sales)  # OK

    2단계: 자신의 데이터로 그래프 만들기¶

plt.title('My Weekly Study Time', fontweight='bold')
plt.ylabel('Hours')
plt.show()

    3단계: 여러 그래프 한번에 보기¶

axes[0, 0].bar(['A', 'B', 'C'], [10, 20, 15])
axes[0, 1].plot([1, 2, 3, 4], [1, 4, 2, 3])
axes[1, 0].scatter([1, 2, 3], [2, 3, 1])
axes[1, 1].hist([1, 2, 2, 3, 3, 3], bins=3)

plt.tight_layout()
plt.show()
