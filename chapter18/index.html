    Chapter 18: 수행평가 워크숍 ③ - Orange3로 내 데이터 모델링¶

    🎯 이 장에서 배우는 것¶

    • 자신이 수집·전처리한 데이터를 Orange3에 불러와 분석 워크플로우를 구성할 수 있다
    • 분석 목적에 맞는 모델(분류/군집화)을 선택하고 적용할 수 있다
    • 모델의 결과를 해석하여 분석 질문에 대한 답을 도출할 수 있다
    • 워크플로우를 보며 자신의 분석 과정을 설명할 수 있다

    💡 왜 이걸 배우나요?¶

    지금까지 여러분은 데이터를 모았고, 정리했고, 탐색했습니다. 하지만 진정한 데이터 분석의 시작은 여기서부터입니다. 이제 "이 데이터가 나에게 말해주는 게 뭘까?"라는 질문에 모델링으로 답하는 단계예요.

    생각해보세요. 마케팅팀이 "어떤 고객이 상품을 구매할까?"라고 묻거나, 의료팀이 "이 증상들로부터 질병을 예측할 수 있을까?"라고 물을 때 우리는 기계학습 모델을 씁니다.

    Orange3는 이 과정을 마우스 클릭만으로 가능하게 해줍니다. 복잡한 코드 없이 자신의 분석 질문을 시각적 워크플로우로 표현하고, 모델의 성능을 즉시 확인할 수 있죠. 이것이 진정한 "데이터 과학자의 일"입니다.

    📚 핵심 개념¶

    개념 1: 분석 질문과 모델의 짝짓기¶

    비유로 시작

    의사가 환자를 진료할 때 "감기"인지 "독감"인지 구분하려면 분류 모델이 필요합니다. 하지만 그 환자가 "어떤 증상의 그룹에 속할까?"를 알고 싶다면 군집화 모델을 써야 합니다. 각 질문마다 맞는 도구가 있다는 뜻이에요.

    정확한 정의

    모델 선택은 분석 질문의 종류에 따라 결정됩니다:

    • 분류(Classification): "이것은 A인가, B인가?"
    • 예: 메일이 스팸인가? / 종양이 악성인가?

    • 모델: 의사결정나무, 로지스틱 회귀, SVM

    • 군집화(Clustering): "이 데이터들은 몇 개의 그룹으로 나뉠까?"

    • 예: 고객을 몇 세그먼트로 분류할 수 있을까? / 비슷한 특징의 제품끼리 묶을 수 있을까?
    • 모델: k-Means, 계층적 군집화

    예시로 확인

    당신이 "우리 카페의 단골 고객은 몇 명일까? 그들은 어떤 특징이 있을까?"라고 물었다면 k-Means 군집화를 씁니다. 하지만 "새로 들어온 고객이 단골이 될까, 일회 고객이 될까?"라고 물었다면 의사결정나무 분류를 씁니다.

    개념 2: Orange3의 워크플로우 구조¶

    비유로 시작

    Orange3의 워크플로우는 공장의 컨베이어 벨트와 같습니다. 원료가 들어와 여러 역할을 하는 기계를 통과하며 완성품이 되어나가죠.

    정확한 정의

    Orange3의 워크플로우는 이렇게 흐릅니다:

    데이터 입력 → 탐색 → 전처리 → 모델 학습 → 평가 → 해석

    각 단계는 위젯(widget)이라는 시각 도구로 표현되며, 위젯들을 선으로 연결하여 데이터가 흐르도록 합니다.

    예시로 확인

    여러분의 "학생 성적 데이터"를 Orange3에 불러온다면:

    1. File 위젯: CSV 파일 불러오기
    2. Data Table 위젯: 데이터 미리보기
    3. Select Columns 위젯: 필요한 열 선택 (예: 성별, 학습시간, 최종성적)
    4. Tree 위젯(의사결정나무): "성별과 학습시간으로 성적을 예측할 수 있을까?" 모델 학습
    5. Confusion Matrix 위젯: 모델이 얼마나 잘 맞혔는지 확인

    개념 3: 훈련 데이터와 테스트 데이터 분할¶

    비유로 시작

    학생이 교과서만 외우고 시험을 본다면, 교과서와 같은 문제가 나올 때만 맞을 겁니다. 중요한 건 본 적 없는 문제를 푸는 능력이죠. 모델도 마찬가지입니다.

    정확한 정의

    모델이 과적합(overfitting)되지 않으려면 데이터를 두 부분으로 나눕니다:

    • 훈련 데이터(Training Data): 모델을 학습시키는 데 사용 (보통 70~80%)
    • 테스트 데이터(Test Data): 모델이 처음 본 데이터로 성능을 평가 (보통 20~30%)

    예시로 확인

    100명의 학생 성적 데이터가 있다면: - 70명으로 모델을 학습: "이 패턴들을 기억해!" - 30명으로 모델을 평가: "정말로 새로운 학생의 성적을 맞출 수 있어?"

    Orange3는 이 분할을 Test & Score 위젯이 자동으로 처리해줍니다.

    개념 4: 모델 결과 해석하기¶

    비유로 시작

    의사가 X선 검사 결과를 얻었다면, 단순히 "암 확률 87%"라는 숫자만으로는 부족합니다. "왜 그럴까? 어떤 부분이 위험한가?"를 설명해야 환자와 치료 계획을 짜죠. 모델 해석도 같습니다.

    정확한 정의

    모델 결과를 해석하는 핵심 메트릭들:

    • 정확도(Accuracy): 전체 중 맞게 예측한 비율
    • 공식: (맞은 예측) / (전체 예측)

    • 해석: "이 모델은 87% 확률로 맞춘다"

    • 혼동 행렬(Confusion Matrix): 어떤 유형의 실수가 나왔는지

    • 진양성(TP): 맞게 '예'라고 함
    • 거짓양성(FP): 틀리게 '예'라고 함 (위험!)
    • 진음성(TN): 맞게 '아니오'라고 함
    • 거짓음성(FN): 틀리게 '아니오'라고 함 (위험!)

    예시로 확인

    "악성 종양 진단 모델"의 혼동 행렬:

    • TP: 정말 악성인데 모델이 악성이라고 함 ✓
    • FP: 양성인데 모델이 악성이라고 함 ✗ (환자가 불안해함)
    • TN: 정말 양성인데 모델이 양성이라고 함 ✓
    • FN: 악성인데 모델이 양성이라고 함 ✗✗ (매우 위험!)

    모델의 정확도가 85%라도, FN이 많으면 이 모델은 실제로는 좋지 못합니다.

    🔨 따라하기¶

    Step 1: 자신의 데이터를 Orange3에 불러오기¶

    준비물: 이전 워크숍에서 전처리한 CSV 파일

    1. Orange3를 열고 새 프로젝트를 만듭니다
    2. 왼쪽 위젯 패널에서 Data → File 을 드래그하여 캔버스에 놓습니다
    3. File 위젯을 더블클릭하여 열고, 자신의 CSV 파일을 선택합니다
    4. File 위젯 옆에 Data → Data Table 을 놓고 File 위젯의 원형 아웃렛에서 Data Table로 연결합니다
    5. Data Table을 실행(▶ 버튼)하여 데이터가 제대로 불러와졌는지 확인합니다

    💡 팁: Data Table에서 각 열의 종류(수치형/문자형)가 올바르게 인식되었는지 확인하세요!

    Step 2: 분석 질문 정하고 분석 위젯 선택하기¶

    이 단계에서 당신의 분석 질문을 명확히 해야 합니다.

    분류 문제를 고르는 경우 (예: "성별을 나이와 구매액으로 예측할 수 있을까?") - Target 변수(예측 대상): 성별 - Feature 변수(예측에 쓸 정보): 나이, 구매액

    군집화 문제를 고르는 경우 (예: "고객을 몇 개 그룹으로 나눌 수 있을까?") - 모든 변수를 feature로 사용 - Target이 없음 (레이블이 없는 학습)

    Step 3: 분류 모델 구성하기 (의사결정나무 예시)¶

    1. Data Table 다음에 Model → Tree 위젯을 연결합니다
    2. Tree를 더블클릭하여 설정 창을 엽니다
    3. Target Variable(목표 변수)로 예측하려는 열을 선택합니다 (예: "성별")
    4. Tree 위젯 옆에 Evaluate → Test & Score 를 놓습니다
    5. Tree의 Learner 아웃렛 → Test & Score의 Learner 입력 포트에 연결
    6. Data Table의 아웃렛 → Test & Score의 Data 입력 포트에 연결
    7. Test & Score를 실행하면 자동으로 7:3으로 데이터 분할하고 모델을 평가합니다
    File → Data Table → Tree → Test & Score
                     ↑
                (Data Table에서 데이터도 입력)

    Step 4: 군집화 모델 구성하기 (k-Means 예시)¶

    1. Data Table 다음에 Model → k-Means 위젯을 연결합니다
    2. k-Means를 더블클릭하여 클러스터 개수(k값)를 설정합니다 (예: k=3)
    3. Visualize → Scatter Plot 을 놓고 k-Means와 Data Table을 연결합니다
    4. Scatter Plot을 더블클릭하여 X축, Y축을 선택합니다 (예: 나이, 구매액)
    5. Scatter Plot을 실행하면 색깔이 다른 점들의 클러스터가 시각화됩니다
    6. 각 클러스터가 "어떤 특징을 가진 고객 그룹인지" 분석합니다
    File → Data Table → k-Means → Scatter Plot
         ↓
      (Data도 Scatter Plot에 연결)

    Step 5: 모델 결과 해석하기¶

    분류 모델의 경우 (Test & Score 창에서): 1. Confusion Matrix 탭을 클릭합니다 2. 대각선(좌상향 → 우하향)의 숫자가 클수록 모델이 잘 작동합니다 3. 각 셀의 숫자를 세어 정확도를 계산합니다: (대각선 합) / (전체 합) × 100%

    군집화 모델의 경우 (Scatter Plot에서): 1. 색깔로 표현된 클러스터들이 명확히 분리되어 있는가를 봅니다 2. 각 클러스터에 속한 데이터들의 공통 특징을 찾습니다 3. "이 클러스터는 어떤 의미일까?"라고 해석합니다

    Step 6: 발견 사항을 문장으로 정리하기¶

    모델이 완성되면, 3-5문장으로 결과를 설명하는 연습을 합니다.

    좋은 해석 예시:

    "의사결정나무 모델로 학생의 성별을 나이와 주간학습시간으로 예측했을 때, 정확도는 81%였습니다. 특히 주간학습시간이 15시간 이상인 학생은 대부분 특정 성별로 분류되었는데, 이는 학습 시간이 성별과 무관한 변수임을 시사합니다."

    피해야 할 해석: - ❌ "정확도가 81%래요" (이게 높은가 낮은가? 왜?) - ❌ "모델이 잘 작동했어요" (무엇을 근거로?) - ❌ "숫자들이 많이 맞았어요" (구체적 수치 필요)

    📝 전체 코드¶

    Orange3는 GUI 기반이므로 "코드"가 아닌 워크플로우입니다. 하지만 자신의 분석 결과를 Python으로 재현하고 싶다면 다음과 같이 합니다:

    # Orange 패키지 설치 (터미널에서)
# pip install orange3

from Orange.data import Table
from Orange.classification import TreeLearner
from Orange.evaluation import CrossValidation, CA
import pandas as pd

# 1. 데이터 불러오기
data = Table("your_data.csv")

# 2. 의사결정나무 모델 생성 및 학습
learner = TreeLearner(max_depth=5)
results = CrossValidation(data, [learner], k=5)  # 5-fold 교차검증

# 3. 정확도 출력
accuracy = CA(results)
print(f"모델 정확도: {accuracy[0]:.2%}")

# 4. k-Means 군집화 (참고용)
from Orange.clustering import KMeans
from Orange.evaluation import silhouette_score

kmeans = KMeans(n_clusters=3)
clustered_data = kmeans(data)

# 시각화 (pandas 활용)
df = pd.DataFrame(data.X, columns=[attr.name for attr in data.domain.attributes])
df['Cluster'] = clustered_data
print(df.groupby('Cluster').describe())

    ⚠️ 자주 하는 실수¶

    실수 1: "이 선이 뭐하는 선이에요?"¶

    • 원인: 위젯 아웃렛(원형 포트)의 데이터 종류를 이해하지 못함
    • 해결: 각 위젯을 더블클릭해서 입력/출력 설정을 확인하세요
    • 빨간 선: 데이터 테이블
    • 파란 선: 학습된 모델
    • 초록 선: 분류 결과

    실수 2: "모델이 90% 정확도인데 왜 우리 데이터로는 80%만 나와요?"¶

    • 원인: 훈련 데이터 vs 테스트 데이터의 차이 미인식
    • 해결: Test & Score를 항상 사용하세요. 훈련 데이터에서만 높은 정확도는 과적합을 의미합니다

    실수 3: "k값을 어떻게 정해요?"¶

    • 원인: 군집화에서 최적 k값을 결정하는 방법을 모름
    • 해결:
    • k=2부터 k=10까지 여러 번 시도해보세요
    • Scatter Plot에서 클러스터가 명확히 분리되는 k값을 고르세요
    • 또는 Elbow Method를 사용하세요 (이후 고급 과정)

    ✅ 스스로 점검하기¶

    자신의 Orange3 워크플로우가 완성되었다면, 다음 질문에 답할 수 있는지 확인하세요:

    1️⃣ 워크플로우 이해도 - ✓ 자신의 워크플로우를 그림으로 그릴 수 있나요? - ✓ 각 위젯이 "어디서 어디로" 데이터를 보내는지 설명할 수 있나요?

    2️⃣ 분석 질문과 모델 선택 - ✓ "왜 이 문제에는 분류/군집화가 맞는가?"를 설명할 수 있나요? - ✓ 다른 모델을 선택했다면 어떤 결과가 나올지 예상할 수 있나요?

    3️⃣ 결과 해석 - ✓ 혼동 행렬의 각 셀이 무엇을 의미하는지 설명할 수 있나요? - ✓ "정확도 85%"가 높은 건지 낮은 건지 판단할 수 있나요? - ✓ 모델의 결과를 3문장 이상으로 설명할 수 있나요?

    4️⃣ 데이터 분할 이해 - ✓ 훈련 데이터와 테스트 데이터가 왜 필요한지 설명할 수 있나요? - ✓ 자신의 모델에서 정확히 몇 개의 데이터가 훈련용/테스트용으로 나뉘었는지 알 수 있나요?

    도전 2: k값 최적화 워크플로우 만들기¶

    k-Means에서 k=2, 3, 4, 5를 동시에 시도하고 각각을 시각화하면, 최적 k값을 더 정확히 찾을 수 있습니다.

    도전 3: 특성 중요도(Feature Importance) 확인하기¶

    Tree 위젯 → Features 탭을 보면, 어떤 열이 모델의 예측에 가장 영향을 미쳤는지 볼 수 있습니다. 이 정보를 토대로 "실제로 예측에 도움이 되는 요소"를 찾아내세요.

    도전 4: 워크플로우 저장하고 수정하기¶

    자신의 워크플로우를 .ows 파일로 저장하면, 나중에 새로운 데이터를 불러와도 같은 분석을 반복할 수 있습니다. 이것이 데이터 분석의 재현성을 보장하는 방법입니다.
