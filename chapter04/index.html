    🎬 Chapter 4: 첫 번째 실습: 우리 반 MBTI 데이터 시각화¶

    🎯 이 장에서 배우는 것¶

    • Google Colab에서 준비된 코드를 실행하고 결과를 확인할 수 있다
    • 자신의 MBTI 데이터를 입력하여 반 전체 시각화 그래프를 만들 수 있다
    • 데이터 시각화의 힘을 직접 체험할 수 있다

    📚 핵심 개념¶

    개념 1: Google Colab - 클라우드 노트북¶

    비유로 이해하기: 구글 독스가 문서 작성의 클라우드 버전이라면, Google Colab은 파이썬 코드 실행의 클라우드 버전입니다. 설치도, 환경 설정도 필요 없어요.

    정의: Google Colab은 구글에서 무료로 제공하는 온라인 파이썬 개발 환경입니다. 누구나 이용할 수 있으며, 셀(Cell) 단위로 코드를 실행할 수 있습니다.

    장점: - 설치 불필요 (브라우저만 있으면 OK) - 구글 드라이브와 자동 연동 - 실행 완료까지 모든 과정을 바로 확인 가능

    개념 2: 셀(Cell) - 코드 블록 단위 실행¶

    비유로 이해하기: 엑셀의 셀처럼, Colab의 셀도 독립적인 실행 단위입니다. 각 셀은 따로따로 실행할 수 있어요.

    실제 모습: - 회색 배경 코드 영역 = 1개 셀 - 실행 버튼(▶) 클릭 = 그 셀만 실행 - 위에서 아래로 순서대로 실행하면 모든 코드가 작동

    개념 3: 데이터 시각화 - 수치를 그림으로¶

    비유로 이해하기: 100명이 MBTI를 말하는 것보다 그래프 하나가 더 빠르게 이해됩니다. 이것이 바로 시각화의 힘!

    정의: 숫자 데이터를 막대그래프, 원형그래프, 선그래프 같은 그림으로 표현하는 것입니다. 우리는 오늘 막대그래프(bar chart)를 만들어요.

    🔨 따라하기¶

    Step 1: Google Colab 링크 열기¶

    할 일: 1. 선생님이 준 링크를 브라우저에서 열기 2. 화면 상단의 "사본 저장" 버튼 클릭 3. 본인의 구글 드라이브에 복사되면 준비 완료!

    왜 사본을 저장할까요? 원본은 건드리지 않고, 우리 반 각자의 데이터를 입력하기 위함입니다. 마치 서식 템플릿을 다운로드한 후 이름을 바꿔서 쓰는 것처럼요.

    Step 2: 내 MBTI 입력하기¶

    할 일: Colab 노트북에서 다음 부분을 찾아서 수정하세요.

    # ===== 여기에 본인의 MBTI를 입력하세요 =====
my_mbti = "ISTJ"  # 예시: "ENFP", "INFJ" 등

    변경 예시: 

    my_mbti = "ENFP"  # 자신의 MBTI로 변경

    주의: 따옴표 안에만 입력하고, 대문자 4글자가 맞는지 확인하세요!

    Step 3: 데이터 입력 셀 실행하기¶

    할 일: 1. my_mbti = "ENFP" 줄이 있는 셀 왼쪽의 ▶ 버튼을 찾으세요 2. ▶ 버튼을 클릭해서 셀 실행 3. 셀 왼쪽에 숫자 [1]이 나타나면 성공!

    화면 모습: 

    [1] (실행 완료 표시)
my_mbti 저장됨 ✓

    Step 4: 모든 반 데이터 병합하기¶

    할 일: "데이터 병합" 셀을 찾아서 실행하세요.

    # 모든 학생의 MBTI 데이터를 하나로 모음
all_data = collect_from_all_students()

    이 셀을 실행하면 우리 반 모든 학생의 MBTI 데이터가 한 곳에 모입니다.

    Step 5: 그래프 그리기¶

    할 lit: "그래프 그리기" 셀의 ▶ 버튼을 클릭하세요.

    import matplotlib.pyplot as plt

# MBTI 개수를 세어서 그래프로 표현
mbti_counts = all_data.value_counts()
mbti_counts.plot(kind='bar', color='skyblue', figsize=(10, 6))
plt.title('우리 반 MBTI 분포')
plt.xlabel('MBTI 유형')
plt.ylabel('명')
plt.show()

    실행 결과 예시: 

    우리 반 MBTI 분포 (컬러풀한 막대그래프가 표시됨)
ENFP: ▓▓▓▓ (4명)
ISTJ: ▓▓▓ (3명)
INFP: ▓▓ (2명)
...

    Step 6: 결과 해석하기¶

    그래프를 보면: - 가장 긴 막대 = 우리 반에서 가장 많은 MBTI 유형 - 가장 짧은 막대 = 우리 반에서 가장 적은 MBTI 유형

    질문 던지기: "어떤 MBTI가 가장 많아? 왜 그럴까?"

    📝 전체 코드¶

    # ===== STEP 1: 내 MBTI 입력하기 =====
my_mbti = "ENFP"  # 여기에 자신의 MBTI를 입력하세요

# ===== STEP 2: 반 전체 데이터 입력 =====
# 선생님이 준비한 전체 데이터 로드
class_mbti_data = [
    "ISTJ", "ENFP", "INFJ", "ISTJ", 
    "ENFP", "ISFP", "INTJ", "ESFJ",
    # ... (우리 반 전체 학생 데이터)
]

# 내 데이터 추가
class_mbti_data.append(my_mbti)

# ===== STEP 3: 시각화하기 =====
import matplotlib.pyplot as plt
from collections import Counter

# MBTI 개수 세기
mbti_counts = Counter(class_mbti_data)
types = list(mbti_counts.keys())
counts = list(mbti_counts.values())

# 막대 그래프 그리기
plt.figure(figsize=(12, 6))
plt.bar(types, counts, color='skyblue', edgecolor='navy', alpha=0.7)
plt.title('우리 반 MBTI 분포', fontsize=16, fontweight='bold')
plt.xlabel('MBTI 유형', fontsize=12)
plt.ylabel('인원 수', fontsize=12)
plt.xticks(rotation=45)
plt.grid(axis='y', alpha=0.3)
plt.tight_layout()
plt.show()

# ===== STEP 4: 통계 정보 출력 =====
print(f"총 인원: {len(class_mbti_data)}명")
print(f"가장 많은 유형: {mbti_counts.most_common(1)[0][0]}")
print(f"가장 적은 유형: {mbti_counts.most_common()[-1][0]}")

    ⚠️ 주의할 점¶

    1️⃣ MBTI는 정확히 4글자 (대문자) - ❌ 잘못된 예: "enfp" (소문자), "ENF" (3글자) - ✅ 올바른 예: "ENFP" (대문자 4글자)

    2️⃣ 에러가 나도 당황하지 마세요! - 에러 메시지는 "비서가 투정부리는 것"일 뿐입니다 - 보통 MBTI 글자가 잘못되었거나, 따옴표를 빠뜨렸을 때 발생합니다 - 천천히 코드를 다시 읽어보세요. 분명 찾을 수 있어요! 😊

    ✅ 점검하기¶

    1. Google Colab에서 셀을 실행하려면 어디를 누르나요?

    정답 확인 셀 왼쪽에 있는 ▶ (재생) 버튼을 클릭합니다. 또는 `Ctrl + Enter`를 누를 수도 있어요.

    2. 우리 반 MBTI 데이터를 "그래프로 나타내는 이유"는 무엇일까요?

    정답 확인 숫자로만 보면 이해하기 어렵지만, 막대그래프로 보면 어떤 MBTI가 많은지 한눈에 비교할 수 있기 때문입니다. 이것이 데이터 시각화의 핵심 목표예요!

    3. 다음 중 올바른 MBTI 형식은? - A) infp - B) "INFP" - C) "INF"

    정답 확인 B) `"INFP"` 입니다. 따옴표로 감싸고, 대문자 4글자여야 합니다.
