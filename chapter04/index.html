    Chapter 04 | 실습 2: Word Cloud + 감정분석¶

    🎯 이 장에서 배우는 것¶

    • 텍스트를 시각적으로 표현하는 Word Cloud를 생성할 수 있다
    • TextBlob으로 문장의 감정을 수치화할 수 있다
    • 두 가지 기술을 조합하여 텍스트 분석을 완성할 수 있다

    📚 핵심 개념¶

    개념 1: Word Cloud (단어 구름)¶

    쉽게 말하면 📊

    자주 나오는 단어를 크게, 적게 나오는 단어를 작게 그려서 "한눈에 어떤 주제인지" 보는 그림입니다. 마치 별자리처럼 중요한 단어들이 빛나는 거죠.

    정의

    텍스트에서 단어의 빈도수를 크기로 표현하는 시각화 기법입니다.

    예시

    "좋아 좋아 싫어"라는 텍스트면 "좋아"는 크게, "싫어"는 작게 표시됩니다.

    개념 2: 감정분석 (Sentiment Analysis)¶

    쉽게 말하면 💭

    "이 문장이 긍정적인가 부정적인가?"를 컴퓨터가 숫자로 판단하는 기술입니다.

    정의

    텍스트에 담긴 감정(긍정/부정/중립)을 자동으로 분석하여 수치로 변환합니다.

    • 극도로 긍정 → +1.0에 가까움
    • 극도로 부정 → -1.0에 가까움
    • 중립적 → 0에 가까움

    🔨 따라하기¶

    Step 1: 필요한 라이브러리 설치하고 Word Cloud 생성하기¶

    코드:

    # 1단계: 라이브러리 설치 및 임포트
from wordcloud import WordCloud
from textblob import TextBlob
import matplotlib.pyplot as plt

# 2단계: 분석할 텍스트 준비
text = """
파이썬은 재미있어 파이썬으로 코딩할 때 정말 행복해
데이터 분석은 미래야 미래의 기술이 여기 있어
프로그래밍은 즐거워 배울수록 더 재미있어
"""

# 3단계: Word Cloud 생성 (세련된 스타일)
wordcloud = WordCloud(
    width=800, 
    height=400,
    font_path='fonts/NanumBarunGothic.ttf',  # 한글 지원
    colormap='magma',  # 고급스러운 색상
    background_color='white'
).generate(text)

# 4단계: 표시
plt.figure(figsize=(12, 6))
plt.imshow(wordcloud, interpolation='bilinear')
plt.axis('off')
plt.show()

    실행 결과:

    "파이썬", "재미있어", "데이터" 같은 주요 단어가 크게 표시되는 시각화 완성! 🎨

    Step 2: 감정분석으로 문장의 감정 수치화하기¶

    코드:

    # 감정분석 함수
def analyze_sentiment(sentence):
    blob = TextBlob(sentence)
    # polarity: -1(부정) ~ +1(긍정)
    polarity = blob.sentiment.polarity
    return polarity

# 여러 문장 분석
sentences = [
    "이 영화 정말 좋았어! 최고야!",      # 긍정
    "너무 재미없어. 시간 낭비야",        # 부정
    "그냥 평범했어",                    # 중립
]

for sentence in sentences:
    score = analyze_sentiment(sentence)
    print(f"'{sentence}' → 감정 점수: {score:.2f}")

    실행 결과:

    '이 영화 정말 좋았어! 최고야!' → 감정 점수: 0.70
'너무 재미없어. 시간 낭비야' → 감정 점수: -0.60
'그냥 평범했어' → 감정 점수: 0.00

    📝 전체 코드¶

    from wordcloud import WordCloud
from textblob import TextBlob
import matplotlib.pyplot as plt

# === Word Cloud 생성 ===
text = """
파이썬 파이썬 코딩 재미있어 행복 데이터 분석
프로그래밍 미래 배우기 즐거움 기술 성장
"""

wordcloud = WordCloud(
    width=800, height=400,
    colormap='magma',
    background_color='white'
).generate(text)

plt.figure(figsize=(12, 6))
plt.imshow(wordcloud, interpolation='bilinear')
plt.axis('off')
plt.title('텍스트의 핵심 단어들')
plt.show()

# === 감정분석 ===
def analyze_sentiment(text):
    blob = TextBlob(text)
    return blob.sentiment.polarity

# 테스트
test_texts = [
    "정말 훌륭한 결과야!",
    "최악이야, 싫어",
    "그냥 괜찮아"
]

for t in test_texts:
    score = analyze_sentiment(t)
    emoji = "😊" if score > 0.3 else "😢" if score < -0.3 else "😐"
    print(f"{emoji} {t} | 점수: {score:.2f}")

    ⚠️ 주의할 점¶

    1. 한글 폰트 문제

    Word Cloud에서 한글이 보이지 않으면: 

    # Google Colab에서 실행

    2. 감정분석의 한계

    TextBlob은 영어 기반이라 한글 감정분석 정확도가 100%가 아닙니다. "에러는 비서의 투정" — 완벽하지 않아도 괜찮아요! 🙌

    ✅ 점검하기¶

    1. 다음 중 Word Cloud의 용도로 가장 적절한 것은?

    ① 정확한 수치 데이터 표현 ② 텍스트에서 중요 단어를 한눈에 파악 ③ 시간 변화 추이 관찰

    정답 확인 ② 텍스트에서 중요 단어를 한눈에 파악 Word Cloud는 시각적 미적 가치도 있지만, 주로 텍스트 데이터에서 빈번한 단어를 빠르게 파악할 때 사용합니다.

    2. TextBlob 감정분석에서 0.8의 의미는?

    ① 매우 부정적 ② 약간 긍정적 ③ 매우 긍정적

    정답 확인 ③ 매우 긍정적 0에서 1.0 사이의 값은 긍정적이며, 0.8은 강한 긍정을 의미합니다.
