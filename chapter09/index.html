    Chapter 09: 판다스 첫 걸음 - 데이터를 불러오고 훑어보기¶

    🎯 이 장에서 배우는 것¶

    • Google Colab에서 CSV 파일을 업로드하고 pd.read_csv()로 불러올 수 있다
    • df.head(), df.shape, df.info()로 데이터의 기본 구조를 파악할 수 있다
    • df.describe()로 평균, 최댓값, 표준편차 등 통계량을 한 번에 확인할 수 있다
    • 데이터 탐색 과정을 체계적으로 진행할 수 있다

    💡 왜 이걸 배우나요?¶

    상상해보세요. 당신이 회사의 마케팅 팀장입니다. 새로운 분석 팀이 고객 데이터 엑셀 파일을 건넵니다. "이 데이터가 몇 개 행으로 되어 있는지, 어떤 열이 있는지, 평균 나이는 몇인지 빨리 알려줘" 라는 요청을 받습니다.

    Pandas 없이라면? 엑셀을 열어서 스크롤하고, 수식을 입력하고, 여러 번 클릭해야 할 겁니다. Pandas로는 3줄의 코드면 모든 게 끝납니다.

    이 장에서 배우는 것들은 매번 데이터 분석을 시작할 때 가장 먼저 하는 작업입니다. 데이터의 '건강상태를 체크하는' 과정이라고 생각하면 됩니다.

    📚 핵심 개념¶

    개념 1: 판다스와 데이터프레임 - "파이썬의 비서"¶

    당신이 회의실에 있는데 누군가 대신 자료를 정리해주는 비서가 있다면? 그게 Pandas입니다.

    정확한 정의: Pandas(판다스)는 파이썬의 데이터 분석 라이브러리입니다. 특히 데이터프레임(DataFrame)이라는 표 형태의 자료구조를 제공하는데, 이게 엑셀처럼 행과 열로 데이터를 정리합니다.

    예시로 확인:

    import pandas as pd

# 영화 데이터를 데이터프레임으로 만들어봅시다
data = {
    '제목': ['기생충', '이웃사람', '승리호'],
    '개봉년도': [2019, 2018, 2021],
    '평점': [8.5, 7.2, 6.8]
}

df = pd.DataFrame(data)
print(df)

        제목  개봉년도  평점
0  기생충   2019  8.5
1  이웃사람   2018  7.2
2  승리호   2021  6.8

    이렇게 행(가로)과 열(세로)로 정리된 구조가 데이터프레임입니다.

    개념 2: CSV 파일 불러오기 - "파일을 손가락 한 번에"¶

    CSV(Comma-Separated Values)는 가장 기본적인 데이터 형식입니다. 엑셀에서 '다른 이름으로 저장'할 때 CSV 형식을 선택하면 됩니다.

    정확한 정의: pd.read_csv()는 CSV 파일을 읽어서 바로 데이터프레임으로 변환하는 함수입니다.

    예시로 확인:

    import pandas as pd

# CSV 파일 불러오기
df = pd.read_csv('영화데이터.csv')

    이 한 줄이면 끝! 복잡한 과정이 모두 자동화됩니다.

    개념 3: 데이터 "훑어보기" - "손가락 네 개로 데이터 장악하기"¶

    데이터를 받으면 가장 먼저 해야 할 일은 "이게 뭐지?"라고 물어보기입니다: - 데이터가 몇 줄인가? - 열은 몇 개인가? - 각 열의 데이터 타입은? - 평균/최댓값은?

    이 모든 질문에 답해주는 함수들이 있습니다:

    head(): 처음 5줄만 보기 (데이터의 '맛' 보기)

    df.head()  # 처음 5줄 출력
df.head(3) # 처음 3줄 출력

    shape: 데이터의 크기 (행 개수, 열 개수)

    df.shape  # (100, 4) → 100줄, 4개 열

    info(): 각 열의 데이터 타입과 빈 칸 여부 확인

    df.info()  # 데이터의 '신분증'을 보는 느낌

    describe(): 숫자 통계량 한 번에 보기 (통계학자 부럽지 않죠?)

    df.describe()  # 평균, 최댓값, 최솟값, 표준편차 모두 보임

    개념 4: 데이터 탐색의 흐름 - "4단계 체크리스트"¶

    마치 새 차를 구매할 때 하는 점검처럼, 데이터도 순서대로 점검합니다:

    1️⃣ 불러오기 (read_csv) 
   ↓
2️⃣ 모양 확인하기 (shape)
   ↓
3️⃣ 처음 몇 줄 보기 (head)
   ↓
4️⃣ 상세 정보 확인 (info, describe)

    이 흐름을 기억하면 어떤 데이터가 와도 당황하지 않습니다.

    Step 1: Google Colab 열고 라이브러리 준비하기¶

    구글 계정이 있다면 Google Colab에 접속하세요.

    Colab에서 새로운 노트북을 만들고 첫 번째 셀에 다음을 입력합니다:

    import pandas as pd
import numpy as np

    Shift + Enter를 눌러 실행하세요. 에러가 없으면 성공!

    Step 2: 예제 데이터 준비하기¶

    우리가 사용할 데이터를 직접 만들어봅시다. Colab의 새로운 셀에 다음을 입력합니다:

    # 영화 데이터셋 만들기

    '제목': ['기생충', '이웃사람', '승리호', '스파이더맨', '겨울왕국'],

    Shift + Enter로 실행합니다. 화면에는 아무것도 나타나지 않지만 df라는 이름의 데이터프레임이 만들어졌습니다.

    Step 3: 첫 번째 질문 - "이 데이터가 몇 줄이냐?"¶

    📝 전체 코드¶

    Colab에서 한 번에 복사-붙여넣기 하면 작동하는 완전한 코드:

    # 1단계: 라이브러리 임포트
import pandas as pd

# 2단계: 데이터 만들기
movies = {
    '제목': ['기생충', '이웃사람', '승리호', '스파이더맨', '겨울왕국'],
    '개봉년도': [2019, 2018, 2021, 2021, 2019],
    '평점': [8.5, 7.2, 6.8, 7.9, 8.1],
    '관객수': [10028955, 6410920, 3088116, 8604975, 7045993]
}

df = pd.DataFrame(movies)

# 3단계: 데이터 탐색 - 4가지 질문
print("="*50)
print("1️⃣ 데이터의 크기")
print("="*50)
print(df.shape)

print("\n" + "="*50)
print("2️⃣ 처음 3줄 보기")
print("="*50)
print(df.head(3))

print("\n" + "="*50)
print("3️⃣ 데이터 타입 확인")
print("="*50)
print(df.info())

print("\n" + "="*50)
print("4️⃣ 통계 요약")
print("="*50)
print(df.describe())

    ⚠️ 자주 하는 실수¶

    실수 1: df.head()와 df.head(3)의 차이를 모르기¶

    df.head()    # ✅ 처음 5줄 (기본값)
df.head(3)   # ✅ 처음 3줄 (내가 지정)
df.head(100) # ✅ 처음 100줄 (데이터가 5줄이면 5줄만 나옴)

    해결: 괄호 안에 숫자를 넣으면 그 개수만큼 출력됩니다.

    실수 2: shape의 순서를 헷갈리기¶

    df.shape  # (5, 4) 

# (행, 열) 순서입니다!
# (5, 4) = 5개 행, 4개 열
# NOT 5개 열, 4개 행 ❌

    해결: (행, 열) = (아래로 센 개수, 옆으로 센 개수)로 기억하세요.

    실시 3: describe()가 텍스트 열은 무시하는 이유를 모르기¶

    describe()는 숫자 열만 통계를 냅니다. 텍스트(object) 열은 평균을 낼 수 없으니까요.

    df.describe()  # 숫자 열(개봉년도, 평점, 관객수)만 나옴
               # 텍스트 열(제목)은 안 나옴

    해결: 이것은 실수가 아니라 Pandas의 똑똑한 설계입니다. 필요하면 다음 장에서 배울 방법으로 텍스트 정보도 볼 수 있습니다.

    실수 4: CSV 파일 경로를 잘못 쓰기¶

    # ❌ 틀린 방법
df = pd.read_csv('영화데이터')      # 확장자 없음

# ✅ 맞는 방법
df = pd.read_csv('영화데이터.csv')  # .csv 확장자 포함

# ✅ 다른 폴더에 있을 때
df = pd.read_csv('./data/영화데이터.csv')

    해결: 파일명 뒤에 .csv 확장자를 반드시 붙이세요.

    도전 1: 당신의 데이터로 해보기¶

    당신이 관심 있는 데이터(좋아하는 노래, 친구들의 생일, 게임 점수 등)를 Pandas 데이터프레임으로 만들어 head(), shape, info(), describe()를 모두 실행해보세요.

    # 예: 당신의 게임 점수 기록
my_game_data = {
    '게임명': ['젤다', '마리오', '포켓몬'],
    '플레이시간': [120, 85, 200],
    '클리어율': [95.5, 78.2, 45.0]
}

df_my_game = pd.DataFrame(my_game_data)
df_my_game.describe()

    도전 2: 함수 조합해보기¶

    # head()와 describe() 함께 쓰기
print("처음 2개 영화:")
print(df.head(2))
print("\n숫자 통계:")
print(df.describe())
