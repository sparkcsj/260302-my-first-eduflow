    Chapter 15: Orange3로 시각화하기 - 클릭만으로 그래프 완성¶

    🎯 이 장에서 배우는 것¶

    • Orange3의 Distributions, Scatter Plot, Box Plot 위젯을 연결하고 실행할 수 있다
    • 클릭 몇 번으로 변수 분포와 변수 간 관계를 시각화할 수 있다
    • 시각화 결과를 읽고 데이터의 특징을 파악할 수 있다
    • 파이썬 코드 시각화 vs Orange3 GUI 시각화의 장단점을 비교할 수 있다

    💡 왜 이걸 배우나요?¶

    지금까지 여러분은 파이썬으로 matplotlib, seaborn 코드를 직접 작성해봤습니다. 코드는 강력하지만, 데이터를 탐색할 때마다 코드를 수정하고 실행하는 과정이 번거롭습니다.

    Orange3는 이 문제를 다르게 접근합니다. 마우스로 드래그하고 위젯을 연결하면 그래프가 실시간으로 나타납니다. 코드를 한 줄도 쓰지 않으면서도 전문적인 시각화를 완성할 수 있죠.

    이 장에서 배우는 건 단순히 "Orange3 사용법"이 아닙니다. 같은 데이터를 두 가지 방식으로 시각화하면서, 상황에 따라 올바른 도구를 선택하는 안목을 키우는 것입니다.

    📚 핵심 개념¶

    개념 1: Orange3의 시각화 철학 - "연결"과 "상호작용"¶

    비유: 레고 블록을 조립하는 것처럼, 각 위젯은 독립적인 부품이고 연결 선으로 데이터를 흘려보냅니다.

    파이썬 코드 방식        →  데이터 로드 → 데이터 정제 → 코드 작성 → 실행 → 그래프
Orange3 위젯 방식       →  [위젯1] → [위젯2] → [위젯3] 실시간 연결

    정확한 정의: Orange3의 시각화는 데이터 흐름(Data Flow) 기반입니다. 한 위젯의 출력이 다음 위젯의 입력이 되면서, 마우스 클릭만으로 탐색적 분석을 수행할 수 있습니다.

    예시로 확인: - 파이썬: plt.scatter(df['age'], df['salary']) → 코드 실행 → 그래프 표시 - Orange3: File 위젯 → Scatter Plot 위젯 연결 → 변수 선택 → 자동으로 그래프 표시

    개념 2: Distributions - "한 변수를 깊게 이해하기"¶

    비유: 반 학생들의 키를 쌓아놓은 모습입니다. 어느 높이에 학생이 가장 많은지, 편차는 어느 정도인지 한눈에 알 수 있죠.

    정확한 정의: Distributions 위젯은 한 변수의 확률분포(histogram, density plot 등)를 표시합니다. 중앙값, 분산, 이상치 등을 시각적으로 파악할 수 있습니다.

    예시로 확인: - 소득 분포가 정규분포인지 (종 모양) → 경제 상황 해석 - 극단적인 이상치가 있는지 → 데이터 오류 가능성

    개념 3: Scatter Plot - "두 변수 간의 숨은 관계 찾기"¶

    비유: 아이스크림 판매량과 기온을 점으로 표시하면, 기온이 올라갈수록 판매량도 늘어나는 패턴이 보입니다.

    정확한 정의: Scatter Plot은 두 개(또는 그 이상)의 연속형 변수를 좌표평면에 점으로 표시하여 변수 간 상관관계, 군집, 이상치를 시각화합니다.

    예시로 확인: - X축: 공부 시간, Y축: 시험 성적 → 직선처럼 모이면 강한 양의 상관 - 색상으로 세 번째 변수 표현 가능 → "남자vs여자 간의 차이" 동시에 파악

    개념 4: Box Plot - "그룹별 분포 한눈에 비교하기"¶

    비유: 여러 상자 안에 구슬을 넣어두고, 각 상자의 구슬 높이 분포를 비교하는 것입니다.

    정확한 정의: Box Plot은 범주형 변수별로 연속형 변수의 분포를 비교합니다. 중앙값, 사분위수, 이상치를 상자와 수염 모양으로 표현합니다.

    예시로 확인: - X축: 학년(1학년, 2학년, 3학년), Y축: 키 → 학년별 키 분포 비교 - 상자가 위로 올라갈수록 → 해당 학년의 평균 키가 크다는 의미

    🔨 따라하기¶

    Step 1: Orange3 실행 및 파일 불러오기¶

    1. Orange3 애플리케이션 실행 → 새 프로젝트 시작
    2. 왼쪽 위젯 패널에서 File 위젯을 캔버스로 드래그
    3. File 위젯 더블클릭 → 다음 중 하나의 데이터셋 선택:
    4. 내장 데이터: Data 폴더 → iris.tab (아이리스 꽃 데이터) 추천

    5. 또는 본인이 준비한 CSV 파일 선택

    6. 우측 캔버스에서 File 위젯이 표시되면 성공

    💡 팁: 처음 배울 때는 iris.tab을 추천합니다. 
깔끔하고 결측치가 없어서 시각화에만 집중할 수 있습니다.

    Step 2: Distributions으로 한 변수 분포 보기¶

    1. 왼쪽 위젯 패널에서 Visualize → Distributions 드래그
    2. File 위젯의 오른쪽 출력 포트 → Distributions의 왼쪽 입력 포트로 선 그리기
    3. Distributions 위젯 더블클릭 → 새 창 열림
    4. 상단 드롭다운에서 변수 선택 (예: sepal length)
    5. 히스토그램과 밀도 곡선이 자동으로 표시됨
    ✅ 확인: Distributions 창에 종 모양 그래프가 나타나면 성공!

    Step 3: 다른 변수로도 Distributions 연결하기¶

    1. 같은 File에서 또 다른 Distributions 위젯 추가
    2. 변수를 petal length로 선택
    3. 두 변수의 분포 모양을 비교 → 데이터 특성 파악
    💡 비교 포인트:
- 두 분포가 모두 대칭인가? (정규분포)
- 한쪽으로 치우쳐 있나? (왜도)
- 이상치가 보이나?

    Step 4: Scatter Plot으로 두 변수 관계 탐색¶

    1. 왼쪽에서 Visualize → Scatter Plot 드래그
    2. File → Scatter Plot 연결
    3. Scatter Plot 더블클릭 → 새 창 열림
    4. X축 드롭다운: sepal length, Y축 드롭다운: sepal width 선택
    5. 우측 하단 점의 색상(Color)을 iris 변수로 설정 → 종별로 색칠됨
    ✅ 확인: 세 종류의 아이리스가 다른 색상으로 표시되면 성공!

    Step 5: Box Plot으로 그룹별 분포 비교¶

    1. Visualize → Box Plot 드래그
    2. File → Box Plot 연결
    3. Box Plot 더블클릭
    4. X축: iris (범주), Y축: sepal length (연속형 변수) 선택
    5. 세 개의 상자가 나타남 → 종별 길이 분포 비교
    ✅  확인: 3개의 상자가 다른 높이에 그려지면 성공!

    Step 6: 선택(Selection) 상호작용으로 데이터 탐색하기¶

    1. Scatter Plot 창으로 돌아가기
    2. 그래프에서 특정 점들을 드래그로 선택 (범위 선택)
    3. 다른 위젯들이 실시간으로 업데이트 됨
    4. 선택된 데이터만 Distributions, Box Plot에도 반영됨
    🎯 의미: 이것이 Orange3의 "상호작용성"입니다!
파이썬은 코드를 다시 수정해야 하지만,
Orange3는 마우스 클릭만으로 탐색이 가능합니다.

    📝 전체 코드¶

    Orange3는 GUI 기반이므로 코드가 필요하지 않습니다. 하지만 같은 결과를 파이썬으로 만들려면 다음과 같습니다:

    import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn import datasets

# iris 데이터 로드 (Orange3와 같은 데이터)
iris = datasets.load_iris()
df = pd.DataFrame(iris.data, columns=iris.feature_names)
df['iris_type'] = iris.target_names[iris.target]

# Step 2: Distributions (히스토그램)
fig, axes = plt.subplots(1, 2, figsize=(12, 4))
axes[0].hist(df['sepal length (cm)'], bins=20, edgecolor='black')
axes[0].set_title('Sepal Length Distribution')
axes[1].hist(df['petal length (cm)'], bins=20, edgecolor='black')
axes[1].set_title('Petal Length Distribution')
plt.show()

# Step 4: Scatter Plot (변수 간 관계)
plt.figure(figsize=(8, 6))
for iris_type in df['iris_type'].unique():
    subset = df[df['iris_type'] == iris_type]
    plt.scatter(subset['sepal length (cm)'], 
                subset['sepal width (cm)'], 
                label=iris_type, alpha=0.7)
plt.xlabel('Sepal Length')
plt.ylabel('Sepal Width')
plt.legend()
plt.show()

# Step 5: Box Plot (그룹별 비교)
plt.figure(figsize=(8, 6))
sns.boxplot(data=df, x='iris_type', y='sepal length (cm)')
plt.show()

    ⚠️ 자주 하는 실수¶

    실수 1: "File 위젯을 놓고 실행했는데 아무것도 안 나온다"¶

    원인: File 위젯을 더블클릭하지 않았거나, 데이터를 선택하지 않음

    해결책: - File 위젯을 반드시 더블클릭하여 파일 선택 창을 열어야 합니다 - "Data" 폴더에서 .tab 파일 또는 .csv 파일을 선택

    실수 2: "위젯을 연결했는데 데이터가 흘러가지 않는다"¶

    원인: 연결 방향이 잘못되었거나, 출력 포트가 아닌 곳에 연결

    확인: - File의 오른쪽 → 다음 위젯의 왼쪽 (항상 이 방향) - 연결선이 흰색이 아니라 회색이면 호환되지 않음

    실수 3: "여러 변수를 한 그래프에 표시하려고 하는데 안 된다"¶

    원인: 각 위젯의 역할을 혼동함

    정확한 이해: - Distributions: 한 번에 1개 변수만 (여러 개를 비교하려면 위젯을 여러 개) - Scatter Plot: X축, Y축 2개 (색상/크기로 3~4개 추가 가능) - Box Plot: X축(범주) + Y축(연속형) 조합

    ✅ 스스로 점검하기¶

    다음 질문에 답할 수 있으면 이 장을 완전히 이해한 것입니다:

    1️⃣ "Scatter Plot에서 선택한 점들이 Box Plot에도 반영되게 하려면?" - 답: File 위젯을 두 위젯 모두에 연결하면 선택이 공유됨

    2️⃣ "iris 데이터에서 'Setosa 종의 꽃받침 길이만' 분포를 보려면?" - 답: Scatter Plot이나 다른 위젯에서 Setosa만 선택 → Distributions이 자동 업데이트

    3️⃣ "파이썬으로 같은 Scatter Plot을 만들려면 코드는 몇 줄?" - 답: 약 10~15줄 (Orange3는 클릭 5번)

    4️⃣ "Box Plot의 X축이 숫자일 때와 텍스트(범주)일 때의 차이점은?" - 답: 숫자면 연속형 변수로 취급(의미 없음), 텍스트면 범주형(의미 있음)

    도전 1: 다중 선택으로 데이터 탐색하기¶

    Scatter Plot에서 여러 번 다른 영역을 선택하고, Distributions이 어떻게 변하는지 관찰하세요. 이것이 탐색적 데이터 분석(EDA)의 핵심입니다.

    도전 2: 자신의 데이터로 시각화하기¶

    개인 데이터(엑셀, CSV)를 File 위젯으로 불러와 같은 과정을 반복하세요. 변수명을 선택할 때 Orange3가 자동으로 감지하는 데이터 타입(숫자/텍스트)을 확인하세요.

    도전 3: Orange3 vs 파이썬 비교표 만들기¶

    이 장에서 배운 내용을 바탕으로: - Orange3가 유리한 경우: 빠른 탐색, 상호작용, 코딩 불필요 - 파이썬이 유리한 경우: 복잡한 전처리, 맞춤형 그래픽, 자동화

    본인의 상황에 맞춰 어떤 도구를 선택할지 정리해보세요.

    다음 장(Chapter 16)에서는 이 시각화를 바탕으로 실제로 머신러닝 모델을 만들고 성능을 평가하는 방법을 배웁니다. Orange3의 모델 학습 위젯(Tree, SVM, Neural Network 등)을 연결하여 예측까지 수행하게 됩니다.

    Orange3의 진정한 강력함은 "시각화 → 모델 학습 → 평가"를 마우스만으로 완성할 수 있다는 데 있습니다. 다음 장에서 확인하세요! 🎯
