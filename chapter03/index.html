    실습 1: MBTI 데이터 시각화¶

    🎯 이 장에서 배우는 것¶

    • Google Colab에서 파이썬 코드를 실행할 수 있다
    • 실제 데이터를 막대그래프로 시각화할 수 있다
    • 데이터 분석의 첫 경험을 해본다

    📚 핵심 개념¶

    개념: 데이터 시각화¶

    마치 숫자만 봐서는 모르는 것을 그림으로 보면 한눈에 알 수 있어요. 예를 들어 "MBTI 유형별 인원" 이라는 데이터가 있을 때, 숫자로만 보면 어떤 유형이 가장 많은지 찾기 어렵습니다. 하지만 막대그래프로 그리면 가장 긴 막대가 즉시 눈에 띕니다.

    정확한 정의: 데이터 시각화는 숫자나 통계를 그래프, 차트 등으로 변환하여 패턴과 의미를 쉽게 발견하는 과정입니다.

    예시: 우리 반 MBTI 결과를 그래프로 그리면 "ISFJ가 가장 많고, ENFP는 1명뿐이네" 같은 정보를 바로 알아챌 수 있죠.

    🔨 따라하기¶

    Step 1: Google Colab 열기 및 데이터 준비¶

    Google Colab(colab.research.google.com)을 열고, 새 노트북을 만든 후 다음 코드를 복사해서 붙여넣기 하세요.

    코드: 

    import matplotlib.pyplot as plt

# 우리 반의 MBTI 데이터 (예시)
mbti_data = {
    'ISFJ': 5, 'INFP': 3, 'ENFP': 1, 
    'ISTJ': 4, 'ESFP': 2, 'ENFJ': 2
}

# 그래프 준비
names = list(mbti_data.keys())
counts = list(mbti_data.values())

plt.figure(figsize=(10, 6))
plt.bar(names, counts, color='skyblue')
plt.xlabel('MBTI 유형')
plt.ylabel('인원수')
plt.title('우리 반의 MBTI 분포')
plt.show()

    Step 2: 코드 실행하기¶

    셀 왼쪽의 재생 버튼(▶)을 누르면 막대그래프가 나타납니다.

    실행 결과: 

    [막대그래프 이미지가 표시됨]
MBTI별 인원을 높이로 비교하는 차트

    📝 전체 코드¶

    import matplotlib.pyplot as plt

# 1. 데이터 준비 (학급 조사 결과)
mbti_data = {
    'ISFJ': 5, 'INFP': 3, 'ENFP': 1, 
    'ISTJ': 4, 'ESFP': 2, 'ENFJ': 2
}

# 2. 딕셔너리를 리스트로 변환
names = list(mbti_data.keys())
counts = list(mbti_data.values())

# 3. 그래프 그리기
plt.figure(figsize=(10, 6))
plt.bar(names, counts, color='skyblue')
plt.xlabel('MBTI 유형', fontsize=12)
plt.ylabel('인원수', fontsize=12)
plt.title('우리 반의 MBTI 분포', fontsize=14)
plt.show()

    ⚠️ 주의할 점¶

    1. 데이터 입력 실수: mbti_data의 유형 이름과 숫자가 맞는지 확인하세요. 한 글자 틀려도 에러가 발생합니다.

    2. 한글 폰트 문제: 한글이 깨지면 코드 첫 줄에 plt.rcParams['font.family'] = 'DejaVu Sans' 를 추가하세요.

    ✅ 점검하기¶

    1. 막대그래프에서 가장 많은 MBTI 유형은 몇 명인가요?

      정답 확인ISFJ로 5명입니다.

    2. plt.bar() 함수의 역할은 무엇인가요?

      정답 확인막대그래프(bar chart)를 그리는 함수입니다. 첫 번째 괄호는 x축(유형 이름), 두 번째는 y축(인원 수)입니다.
