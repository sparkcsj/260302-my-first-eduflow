    Chapter 03. 평가, 다 보여줄게 - 수행평가 & 지필 완전 공개¶

    🎯 이 장에서 배우는 것¶

    • 6단계 수행평가의 주제, 배점, 일정을 정확히 파악할 수 있다
    • 지필평가의 범위와 출제 방향을 이해할 수 있다
    • 자신만의 간단한 학기 학습 계획을 세울 수 있다

    📚 핵심 개념¶

    개념 1: 수행평가의 구조 (총 60점)¶

    비유로 시작
    수행평가는 마치 요리 경연처럼, 레시피(아이디어) → 재료 준비(수집) → 손질(전처리) → 요리(모델링) → 플레이팅(발표) 각 단계마다 심사를 받는 것과 같아요.

    정확한 정의
    6개 단계로 나뉜 평가로, 각 단계에서 필요한 산출물과 능력을 평가합니다.

    6단계 배점 구조: - 수행 1단계: 아이디어 & 주제 설계 → 10점 - 수행 2단계: 데이터 수집 & 출처 명시 → 10점 - 수행 3단계: 데이터 전처리 & 시각화 → 10점 - 수행 4단계: 머신러닝 모델링 → 15점 - 수행 5단계: 포스터 & 결과 정리 → 15점 - 수행 6단계: 발표 및 질의응답 → 10점 - 지필평가: 객관식 & 주관식 시험 → 40점

    개념 2: 각 수행평가 단계의 구체적 내용¶

    1단계: 아이디어 & 주제 설계 (10점)

    여기서는 "어떤 데이터로 무엇을 분석할 것인가"를 정합니다.

    예시: - ✅ 좋은 주제: "서울시 지하철역별 승객 수 데이터로 혼잡도 예측 모델 만들기" - ❌ 나쁜 주제: "데이터를 가지고 뭔가 한다"

    평가 포인트: 주제의 명확성, 데이터 출처 사전 확인, 분석 목표의 구체성

    2단계: 데이터 수집 (10점)

    선택한 주제에 맞는 데이터를 실제로 찾아오고 정리합니다.

    예시: 

    # 공개 데이터 사이트에서 CSV 다운로드
# 예: Kaggle, 공공데이터포털, UCI ML Repository
import pandas as pd

data = pd.read_csv('subway_passengers.csv')
print(data.head())  # 첫 5행 확인

    평가 포인트: 데이터 출처 명시, 파일 형식의 적절성, 데이터 규모(최소 100행 이상)

    3단계: 데이터 전처리 & 시각화 (10점)

    수집한 데이터를 깨끗하게 정리하고 그래프로 표현합니다.

    # 결측치 제거/채우기
data = data.dropna()  # 또는 data.fillna(data.mean())

# 기본 통계량 확인
print(data.describe())

# 시각화
import matplotlib.pyplot as plt
plt.hist(data['passenger_count'], bins=30)
plt.xlabel('승객 수')
plt.show()

    평가 포인트: 결측치 처리 방법 설명, 이상치 탐지, 최소 3개 이상의 시각화

    4단계: 머신러닝 모델링 (15점) ⭐ 가장 높은 배점

    여기가 가장 중요한 단계입니다. 배운 머신러닝 알고리즘을 실제로 적용합니다.

    from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

    X, y, test_size=0.2, random_state=42

# 모델 학습

model.fit(X_train, y_train)

    평가 포인트: 모델 선택의 타당성, 성능 평가 방법 설명, 결과 해석

    5단계: 포스터 & 결과 정리 (15점)

    분석 전체 과정을 A4 또는 A3 크기의 포스터로 시각적으로 정리합니다.

    포스터 구성: - 제목 & 팀원명 - 연구 배경 (왜 이 주제?) - 데이터 & 방법론 - 분석 결과 (그래프, 모델 성능) - 결론 & 제언

    평가 포인트: 정보의 명확성, 시각적 구성, 과정의 논리성

    6단계: 발표 & 질의응답 (10점)

    포스터를 기반으로 3분 정도 발표하고 질문에 답합니다.

    평가 포인트: 전달력, 전문성, 질의응답의 정확성

    개념 3: 지필평가의 구조 (40점)¶

    비유로 시작
    지필평가는 마치 음악 시험에서 실제 연주(수행평가) 후에 악보를 읽고 이론을 아는지 확인하는 것과 같습니다.

    평가 범위: - Part 1: 데이터과학 개념 (데이터 종류, 윤리) - Part 2: 데이터 수집 & 전처리 (결측치, 정규화) - Part 3: 시각화 원리 (그래프 선택 기준) - Part 4: 머신러닝 기초 (지도/비지도학습, 성능 평가)

    출제 형식: - 객관식 25점 (1~25번, 각 1점) - 단답형 10점 (코드 필기, 개념 설명) - 서술형 5점 (분석 사례 해석)

    📝 전체 코드: 나만의 학기 계획 작성 템플릿¶

    # 개인 학습 계획 작성 프로그램
import json
from datetime import datetime

class StudyPlanner:
    def __init__(self, name):
        self.name = name
        self.plan = {}
        self.total_hours = 0

    def add_stage(self, stage_name, deadline, tasks, hours):
        """각 단계별 계획 추가"""
        self.plan[stage_name] = {
            "deadline": deadline,
            "tasks": tasks,
            "hours": hours,
            "completed": False
        }
        self.total_hours += hours

    def print_plan(self):
        """전체 계획 출력"""
        print(f"\n{'='*50}")
        print(f"📋 {self.name}의 데이터과학 학기 계획")
        print(f"{'='*50}\n")

        for stage, info in self.plan.items():
            print(f"📅 {stage}")
            print(f"   마감일: {info['deadline']}")
            print(f"   예상 시간: {info['hours']}시간")
            print(f"   해야할 일:")
            for task in info['tasks']:
                print(f"      □ {task}")
            print()

        print(f"총 예상 학습 시간: {self.total_hours}시간")

# 실제 사용
my_plan = StudyPlanner("김데이터")

my_plan.add_stage(
    "1단계: 주제 설계",
    "3월 22일",
    ["주제 정하기", "데이터 출처 확인", "분석 목표 정의"],
    3
)

my_plan.add_stage(
    "2단계: 데이터 수집",
    "4월 12일",
    ["데이터 다운로드", "형식 확인", "규모 확인"],
    4
)

my_plan.add_stage(
    "4단계: 모델링",
    "5월 24일",
    ["머신러닝 알고리즘 선택", "학습 및 평가", "결과 분석"],
    8
)

my_plan.add_stage(
    "지필평가 준비",
    "6월 28일",
    ["개념 정리", "문제 풀이", "실전 모의"],
    10
)

my_plan.print_plan()

    ⚠️ 주의할 점¶

    주의 1: 수행평가는 단계별로 진행됨
    이전 단계를 완료하지 않고 다음 단계로 넘어가면 안 됩니다. 예를 들어, 주제가 명확하지 않으면 데이터 수집도 어렵습니다. 각 단계를 충실히 해야 합니다.

    주의 2: 지필평가는 개념 이해가 핵심
    수행평가에서 높은 점수를 받았다고 해도 지필에서 개념을 모르면 감점됩니다. 각 챕터를 읽으면서 "왜 이렇게 하는가?"를 항상 자문하세요.

    ✅ 점검하기¶

    1. 전체 배점 중 지필평가의 비중은?

    정답 확인 40점 / 100점 = 40%. 지필평가가 가장 큰 비중을 차지합니다.

    2. 4단계 모델링과 5단계 포스터의 합계 배점은?

    정답 확인 15점 + 15점 = 30점. 즉, 지필 40점을 제외하면 실무 능력 평가의 절반이 이 두 단계에 집중되어 있습니다.

    3. 당신이라면 어느 단계에 가장 많은 시간을 투자하겠는가? 그 이유는?

    정답 예시 학생마다 다르지만, 추천은: - "4단계 모델링": 머신러닝이 가장 어렵고, 여기서 잘해야 결과가 좋음 - "지필 준비": 배점이 가장 크므로 개념을 확실히 해야 함 - "1단계 주제": 주제가 좋아야 전체 프로젝트의 질이 결정됨
