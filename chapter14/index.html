    Chapter 14. Orange3 첫 만남 - 설치부터 위젯 탐험까지¶

    🎯 이 장에서 배우는 것¶

    • Orange3를 설치하고 기본 인터페이스를 탐험할 수 있다
    • File 위젯으로 데이터를 불러올 수 있다
    • 위젯을 연결하여 간단한 워크플로우를 만들 수 있다
    • Data Table 위젯으로 데이터를 확인할 수 있다

    💡 왜 이걸 배우나요?¶

    지금까지 파이썬으로 데이터 분석 코드를 직접 작성했다면, 이제는 완전히 다른 경험을 할 차례입니다. Orange3는 코딩 없이 마우스 클릭만으로 머신러닝 분석을 할 수 있는 도구예요.

    "코딩 없다고?"라고 놀라셨다면, 정확합니다. Orange3는 레고 블록처럼 위젯(작은 기능 단위)을 끌어다 놓고, 선으로 연결하면 데이터가 자동으로 흘러가는 방식입니다.

    🧩 비유로 이해하기 - 레고: 블록을 끼우듯이 → Orange3: 위젯을 캔버스에 배치 - 전자회로: 부품을 와이어로 연결 → Orange3: 위젯을 선으로 연결 - 파워포인트: 슬라이드를 순서대로 → Orange3: 워크플로우를 시각적으로 구성

    Orange3의 진가는 탐색적 데이터 분석(EDA)과 빠른 프로토타이핑입니다. 복잡한 전처리 로직을 한눈에 볼 수 있고, 파라미터를 즉시 변경해서 결과를 확인할 수 있거든요.

    📚 핵심 개념¶

    개념 1: Orange3는 무엇인가?¶

    정의: Orange3는 오픈소스 머신러닝 플랫폼으로, 비프로그래머도 사용할 수 있도록 설계된 시각적 데이터 마이닝 도구입니다.

    특징: - 노코드(No-Code) 분석: 파이썬을 몰라도 괜찮아요 - 시각적 워크플로우: 처리 과정이 화면에 그대로 보여요 - 풍부한 위젯: 데이터 로드부터 머신러닝, 시각화까지 모두 가능 - 파이썬 연동: 필요하면 파이썬 스크립트 위젯으로 확장 가능

    개념 2: 위젯(Widget)의 개념¶

    정의: 위젯은 Orange3의 최소 작업 단위입니다. 하나의 기능을 담당하는 블록이에요.

    예시: - File 위젯: 데이터 파일을 불러온다 - Data Table 위젯: 데이터를 표 형태로 보여준다 - Select Columns 위젯: 특정 열만 선택한다 - Tree 위젯: 의사결정 나무 모델을 만든다

    개념 3: 워크플로우(Workflow)¶

    정의: 여러 위젯을 선으로 연결하여 데이터가 순차적으로 처리되는 전체 흐름입니다.

    [데이터 파일] → [전처리] → [모델학습] → [결과 시각화]

    각 화살표가 와이어(Wire)이고, 화살표를 따라 데이터가 흘러갑니다.

    개념 4: 캔버스(Canvas)¶

    정의: 위젯을 배치하고 연결하는 작업 공간입니다. 백지와 같죠.

    🔨 따라하기¶

    Step 1: Orange3 설치하기¶

    Option A: 독립 실행 파일 (추천 👍)

    1. Orange3 공식 사이트에서 Download 클릭
    2. 운영체제별 설치 파일 선택:
    3. Windows: .exe 파일
    4. macOS: .dmg 파일
    5. Linux: 패키지 관리자 사용
    6. 설치 파일 실행 → Next 연타 → 설치 완료

    설치 시간: 약 5분

    Option B: 파이썬 패키지로 설치

    pip install orange3
orange-canvas

    Step 2: Orange3 첫 실행과 인터페이스 탐험¶

    Orange3를 실행하면 다음과 같은 화면이 나타납니다:

    ┌─────────────────────────────────────────────────────────┐
│ Orange Canvas                                     [_][□][X]
├─────────────────┬─────────────────────────────────────────┤
│  위젯 패널      │                                         │
│  (좌측)         │        캔버스(중앙)                     │
│  ├─ Data       │        (백지)                           │
│  ├─ Visualize  │                                         │
│  ├─ Model      │                                         │
│  └─ Evaluate   │                                         │
├─────────────────┴─────────────────────────────────────────┤
│ 상태 바 (하단) - 메시지 표시                              │
└─────────────────────────────────────────────────────────────┘

    좌측 위젯 패널: 모든 위젯이 카테고리별로 정렬되어 있어요.

    • Data: 데이터 불러오기, 전처리
    • Visualize: 그래프, 차트 그리기
    • Model: 머신러닝 모델
    • Evaluate: 모델 성능 평가

    중앙 캔버스: 위젯을 끌어서 놓는 작업 공간입니다.

    Step 3: File 위젯으로 데이터 불러오기¶

    1. 좌측 Data 카테고리 펼치기
    2. File 위젯을 클릭 후 캔버스에 드래그
    3. File 위젯이 캔버스에 나타나면 더블클릭
    4. 데이터 선택 대화창 열림:
    5. Browse data file 클릭
    6. 또는 하단의 내장 데이터 선택 (예: iris 데이터)

    팁: 처음 사용자라면 내장 데이터 iris.tab을 선택하세요. 유명한 붓꽃 분류 데이터입니다.

    Step 4: Data Table 위젯 추가¶

    1. Data 카테고리에서 Data Table 위젯 찾기
    2. 캔버스에 드래그해서 놓기
    3. File 위젯의 오른쪽 끝에서 시작하는 선을 Data Table로 드래그

    선(와이어)이 연결되면, Data Table에 데이터가 자동으로 표시됩니다.

    [File] ──────→ [Data Table]

    Step 5: 데이터 확인하고 탐험하기¶

    Data Table 위젯을 더블클릭하면: - 데이터가 표 형태로 보여집니다 - 행(샘플): 150개 - 열(특성): sepal_length, sepal_width, petal_length, petal_width, iris - 스크롤해서 더 많은 데이터 확인 가능

    Step 6: Select Columns로 열 선택해보기¶

    1. Data 카테고리에서 Select Columns 위젯 추가
    2. File → Select Columns 연결
    3. Select Columns → Data Table 다시 연결
    4. Select Columns 더블클릭 후 원하는 열만 선택
    5. Data Table에서 선택된 열만 표시되는 것 확인

    축하합니다! 🎉 첫 워크플로우를 완성했어요!

    📝 전체 코드¶

    이 장에서는 코드가 아닌 시각적 조작이 주입니다. 다만, 나중에 파이썬으로 같은 작업을 하려면:

    import pandas as pd
from sklearn.datasets import load_iris

# Iris 데이터 불러오기
iris = load_iris()
df = pd.DataFrame(iris.data, columns=iris.feature_names)
df['species'] = iris.target_names[iris.target]

# 데이터 확인
print(df.head())
print(df.shape)  # (150, 5)

# 특정 열만 선택
selected = df[['sepal_length', 'sepal_width']]
print(selected.head())

    Orange3는 이 모든 과정을 마우스로 합니다!

    ⚠️ 자주 하는 실수¶

    실수 1: 위젯을 추가만 하고 연결하지 않음¶

    ❌ 잘못된 경우 

    [File]            [Data Table]
(연결 안 됨)

    ✅ 올바른 경우 

    [File] ──→ [Data Table]

    해결책: File 위젯의 오른쪽 끝에서 동그란 포트가 보입니다. 그 포트에서 드래그하여 Data Table로 연결하세요.

    실수 2: 데이터가 로드되지 않은 상태로 계속 진행¶

    ❌ 증상: File 위젯에 작은 삼각형 경고 마크가 나타남

    해결책: File 위젯을 더블클릭해서 반드시 데이터 파일을 선택하세요.

    실수 3: 위젯을 닫아버림¶

    Orange3에서 위젯의 [X] 버튼은 데이터 연결을 끊는 게 아니라 위젯 전체를 삭제합니다.

    해결책: 위젯을 "최소화"하려면 [-] 버튼을 쓰세요. 완전히 제거하려면 Delete 키를 눌러야 합니다.

    🚀 더 해보기¶

    도전 1: 다른 내장 데이터 탐험하기¶

    File 위젯을 다시 열어서 다른 데이터를 시도해보세요: - wine.tab: 와인 분류 데이터 - housing.tab: 주택 가격 예측 데이터 - titanic.tab: 타이타닉 생존자 데이터

    각 데이터가 몇 개 샘플과 특성을 가졌는지 확인하면 데이터 이해에 도움이 됩니다.

    도전 2: 워크플로우에 Scatter Plot 추가하기¶

    1. Visualize 카테고리에서 Scatter Plot 위젯 추가
    2. Select Columns → Scatter Plot 연결
    3. Scatter Plot을 더블클릭해서 X축과 Y축 선택
    4. Iris 데이터가 산점도로 시각화되는 것을 확인

    재미있는 발견: Iris의 품종(setosa, versicolor, virginica)이 자연스럽게 분리되는 것이 보일 거예요!

    도전 3: 워크플로우 저장하고 불러오기¶

    1. File 메뉴 → Save Workflow
    2. 파일명을 my_first_workflow.ows로 지정
    3. Orange3를 종료했다가 다시 실행
    4. File → Open Workflow 클릭
    5. 저장한 워크플로우가 그대로 복원되는 것 확인
