    Chapter 10: 더러운 데이터, 깨끗하게 - 결측값과 이상값 처리¶

    🎯 이 장에서 배우는 것¶

    • 결측값(NaN)을 찾아내고 그 영향을 파악할 수 있다
    • 결측값을 삭제하거나 대체하는 방법을 실습할 수 있다
    • 이상값이 분석 결과를 어떻게 왜곡하는지 체감할 수 있다
    • 두 가지 전처리 방법의 장단점을 비교할 수 있다

    💡 왜 이걸 배우나요?¶

    가장 현실적인 문제부터 시작하겠습니다.

    설문조사를 했는데, 한 사람의 나이 칸이 비어있다면? 아니면 누군가 나이에 999를 적었다면? 이런 '더러운' 데이터로 평균을 계산하면 엉뚱한 결과가 나옵니다.

    실제 공공데이터의 80%는 결측값이나 이상값을 포함하고 있습니다. 이를 처리하지 않으면:

    • 결론이 틀림: 평균 나이가 500세가 될 수 있어요
    • 에러 발생: 프로그램이 갑자기 깨져요
    • 신뢰도 하락: 분석 결과를 믿을 수 없어요

    따라서 분석 전 데이터 정제는 필수 과정입니다. 마치 요리하기 전에 채소를 씻는 것처럼요.

    📚 핵심 개념¶

    개념 1: 결측값(Missing Value, NaN)¶

    비유: 온라인 주문서에서 '전화번호' 칸을 비워둔 고객처럼, 데이터에서 값이 없는 상태입니다.

    정의: 데이터가 수집되지 않았거나 기록되지 않은 빈 칸. 파이썬에서는 NaN(Not a Number)이나 None으로 표현됩니다.

    발생 원인: - 설문 응답 안 함 (회피) - 센서 오류 (기술적 문제) - 데이터 손상 (저장 실패) - 관찰 불가능 (예: 망자의 현재 나이)

    예시 확인:

    import pandas as pd
import numpy as np

# 결측값이 포함된 데이터
data = {
    '이름': ['철수', '영희', '민준', '지은'],
    '나이': [25, np.nan, 30, np.nan],  # np.nan = 결측값
    '소득': [3000, 2500, np.nan, 2800]
}
df = pd.DataFrame(data)
print(df)

    출력: 

       이름    나이     소득
0  철수  25.0  3000.0
1  영희   NaN  2500.0
2  민준  30.0    NaN
3  지은   NaN  2800.0

    NaN은 "값이 없다"를 의미합니다. 0과는 다릅니다!

    개념 2: 결측값 탐지 방법¶

    개념: 데이터에서 NaN을 찾아내는 과정

    주요 메서드:

    isna() 또는 isnull(): 각 값이 NaN인지 True/False로 반환

    # 위의 df 계속 사용
print(df.isna())  # True/False 표시
print(df.isnull())  # 동일 (둘 다 사용 가능)

    출력: 

        이름     나이     소득
0  False  False  False
1  False   True  False
2  False  False   True
3  False   True  False

    info() 메서드: 결측값 개수를 한눈에 파악

    df.info()

    출력: 

    <class 'pandas.core.frame.DataFrame'>
RangeIndex: 4 entries, 0 to 3
Data columns (total 3 columns):
 이름    4 non-null object
 나이    2 non-null float64      # ← 2개만 값 있음 (2개 결측)
 소득    3 non-null float64      # ← 3개만 값 있음 (1개 결측)

    개념 3: 이상값(Outlier)¶

    비유: 반 학생들 키가 160~180cm인데 한 명이 250cm라면? 명백히 이상하죠.

    정의: 다른 데이터와 크게 벗어난 극단적인 값

    종류: - 기록 오류: 나이에 999 입력 - 측정 오류: 온도계 고장 - 실제 이상: 극도로 부유한 사람의 소득

    영향:

    # 정상 데이터
normal_data = [25, 28, 26, 27, 29]
print(f"평균: {np.mean(normal_data)}")  # 27.0

# 이상값 포함
with_outlier = [25, 28, 26, 27, 999]  # 999 = 오류
print(f"평균: {np.mean(with_outlier)}")  # 211.0 (완전히 틀림!)

    이상값의 영향: 평균이 27에서 211로 변함! 📊

    개념 4: 결측값 처리 전략¶

    두 가지 대표 전략:

    결측값 발견
    ↓
[1] 삭제 (dropna)     [2] 대체 (fillna)
    ↓                     ↓
행 제거            평균값으로 채우기
데이터 손실         데이터 보존

    삭제 전략 (Deletion): - 장점: 간단하고 확실함 - 단점: 데이터 손실, 표본 크기 감소 - 사용 시기: 결측값이 소수(5% 이하)일 때

    대체 전략 (Imputation): - 장점: 데이터 손실 없음 - 단점: 인공적 값 생성, 분석 왜곡 가능 - 사용 시기: 결측값이 많을 때

    🔨 따라하기¶

    Step 1: 샘플 데이터 만들기¶

    실제 분석 상황을 재현합니다. 공공데이터처럼 결측값과 이상값이 섞여 있는 데이터를 만들겠습니다.

    import pandas as pd
import numpy as np

# 온라인 쇼핑몰 고객 데이터
data = {
    '고객ID': [1, 2, 3, 4, 5, 6, 7, 8],
    '나이': [25, np.nan, 35, 999, 28, 31, np.nan, 26],  # NaN과 이상값 섞임
    '구매액': [50000, 75000, np.nan, 120000, 60000, np.nan, 85000, 55000]
}

df = pd.DataFrame(data)
print("원본 데이터:")
print(df)
print("\n결측값 현황:")
print(df.isnull().sum())  # 각 열의 결측값 개수

    Step 2: 결측값 탐지 및 통계 확인¶

    # 결측값이 있는 행 확인
print("결측값이 있는 행:")
print(df[df.isnull().any(axis=1)])  # 하나라도 NaN이 있으면 True

# 결측값 비율 확인
print("\n결측값 비율:")
print(df.isnull().sum() / len(df) * 100)  # 각 열의 결측값 비율 (%)

    Step 3: 이상값 확인 - 현황 파악¶

    원본 데이터로 기본 통계를 계산하고, 이상값의 영향을 체감합니다.

    # 나이의 기본 통계 (이상값 999 포함)
print("나이 통계 (이상값 포함):")
print(df['나이'].describe())
print(f"평균: {df['나이'].mean()}")  # 이상값 때문에 높음

    Step 4: 전략 1 - 삭제하기 (dropna)¶

    결측값이 있는 행을 완전히 제거합니다.

    # 방법 1: 결측값이 있는 행 모두 삭제
df_dropped = df.dropna()
print("삭제 후 데이터:")
print(df_dropped)
print(f"행 개수: {len(df)} → {len(df_dropped)}")  # 8개에서 3개로 감소!

# 확인: 평균 재계산
print(f"\n나이 평균 (이상값 제거 후): {df_dropped['나이'].mean()}")

    Step 5: 전략 2 - 대체하기 (fillna)¶

    결측값을 평균값으로 채웁니다.

    # 먼저 이상값(999) 제거
df_clean = df[df['나이'] != 999].copy()

# 결측값을 평균값으로 채우기
mean_age = df_clean['나이'].mean()  # 999 제외하고 계산: 27.5
mean_purchase = df_clean['구매액'].mean()

df_filled = df_clean.fillna({
    '나이': mean_age,
    '구매액': mean_purchase
})

print("대체 후 데이터:")
print(df_filled)
print(f"\n나이 평균 (값 대체 후): {df_filled['나이'].mean()}")

    Step 6: 결과 비교¶

    print("=== 처리 방법별 나이 평균 비교 ===")
print(f"1. 원본 (이상값 포함): {df['나이'].mean():.1f}")  # NaN 무시, 999 포함
print(f"2. 삭제 (dropna): {df_dropped['나이'].mean():.1f}")
print(f"3. 대체 (fillna): {df_filled['나이'].mean():.1f}")

    📝 전체 코드¶

    import pandas as pd
import numpy as np

# === Step 1: 데이터 준비 ===
data = {
    '고객ID': [1, 2, 3, 4, 5, 6, 7, 8],
    '나이': [25, np.nan, 35, 999, 28, 31, np.nan, 26],
    '구매액': [50000, 75000, np.nan, 120000, 60000, np.nan, 85000, 55000]
}
df = pd.DataFrame(data)

# === Step 2: 결측값 탐지 ===
print("원본 데이터 결측값:")
print(df.isnull().sum())

# === Step 3: 이상값 확인 ===
print("\n나이 통계 (이상값 999 포함):")
print(f"평균: {df['나이'].mean():.1f}")  # 이상값 때문에 높음

# === Step 4: 삭제 전략 ===
df_dropped = df.dropna()
print(f"\n삭제 후 나이 평균: {df_dropped['나이'].mean():.1f}")

# === Step 5: 대체 전략 ===
df_clean = df[df['나이'] != 999].copy()
mean_age = df_clean['나이'].mean()
df_filled = df_clean.fillna({'나이': mean_age})
print(f"대체 후 나이 평균: {df_filled['나이'].mean():.1f}")

# === Step 6: 결과 비교 ===
print("\n=== 최종 비교 ===")
print(f"행 개수: 원본({len(df)}) → 삭제({len(df_dropped)}) → 대체({len(df_filled)})")

    ⚠️ 자주 하는 실수¶

    실수 1: NaN과 0을 같다고 생각하기¶

    # ❌ 틀린 방법
df[df['나이'] == 0]  # 0인 행 찾기 (결측값 못 찾음)

# ✅ 올바른 방법
df[df['나이'].isna()]  # NaN인 행 찾기

    왜 틀렸나? NaN은 수치가 아니라 "값이 없음"이므로 == 비교가 작동하지 않습니다.

    실수 2: 이상값을 무시하고 분석하기¶

    # ❌ 이상값을 모르고 진행
평균 = df['나이'].mean()  # 999 포함시 엄청 높아짐

# ✅ 이상값을 먼저 점검
print(df['나이'].describe())  # max 값 확인
df[df['나이'] > 100]  # 의심스러운 값 찾기

    대처법: 분석 전에 항상 describe()로 최댓값/최솟값을 확인하세요.

    실수 3: 너무 많은 데이터를 삭제하기¶

    # ❌ 결측값 하나만 있어도 전체 행 삭제
df.dropna()  # 데이터 대부분 사라짐!

# ✅ 중요한 열만 기준으로 삭제
df.dropna(subset=['고객ID', '나이'])  # 이 두 열만 필수

    원칙: 각 상황에 맞는 선택적 삭제가 중요합니다.

    ✅ 스스로 점검하기¶

    아래 문제를 풀어보세요. 코드 없이 개념으로 답하면 됩니다.

    1번: 결측값 탐지

    다음 데이터에서 결측값이 몇 개인가요? 

    data = [10, np.nan, 20, np.nan, 30]

    정답 보기 2개입니다. np.nan이 2번 나타났으므로 결측값도 2개입니다.

    2번: 처리 전략 선택

    1,000개 행 중 5개만 결측값이 있습니다. 삭제할까요, 대체할까요?

    정답 보기 삭제하세요. 0.5%밖에 안 되므로 삭제해도 데이터 손실이 미미합니다. 대체는 불필요한 인공값을 만듭니다.

    3번: 이상값 파악

    나이의 최댓값이 150이라고 나왔습니다. 뭘 해야 할까요?

    정답 보기 먼저 그 행을 확인해야 합니다. 데이터 입력 오류(1500을 150으로 잘못 입력)일 수 있고, 실제 데이터일 수도 있으니까요. `df[df['나이'] == 150]`으로 확인한 후 판단하세요.

    🚀 더 해보기¶

    심화 1: 조건부 처리¶

    같은 그룹끼리만 대체하기 (예: 남성은 남성 평균, 여성은 여성 평균)

    # groupby를 이용한 그룹별 평균 대체
df['나이'] = df.groupby('성별')['나이'].transform(
    lambda x: x.fillna(x.mean())
)

    심화 2: 이상값의 통계적 정의¶

    IQR(사분위수 범위)를 이용한 객관적 판단

    Q1 = df['나이'].quantile(0.25)
Q3 = df['나이'].quantile(0.75)
IQR = Q3 - Q1

# Q1 - 1.5*IQR 이하거나 Q3 + 1.5*IQR 이상이면 이상값
outliers = df[(df['나이'] < Q1 - 1.5*IQR) | (df['나이'] > Q3 + 1.5*IQR)]
