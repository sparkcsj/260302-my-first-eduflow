    01. 흥미 유발: 데이터로 본 외고인의 하루¶

    🎯 이 장에서 배우는 것¶

    • 일상 속 숨겨진 데이터를 발견할 수 있다
    • 데이터과학이 우리 생활과 밀접한 관련이 있음을 이해할 수 있다
    • 간단한 데이터 분석의 즐거움을 경험할 수 있다

    📚 핵심 개념¶

    개념: 데이터과학(Data Science)¶

    데이터과학은 마치 탐정이 단서를 찾아 사건을 해결하는 것과 같아요. 우리 주변의 숫자와 정보들 속에서 숨겨진 이야기를 찾아내는 학문입니다.

    정의: 데이터를 수집, 분석, 시각화하여 의미 있는 패턴이나 인사이트를 발견하는 과정

    예시: 외고 학생들의 등교 시간 데이터를 분석해보면... - 8시 10분: 전체의 60% 등교 (가장 많음!) - 이유는? → 1교시 시작 20분 전, 최적의 여유시간

    🔨 따라하기¶

    Step 1: 외고생 데이터 살펴보기¶

    # 외고생 100명의 하루 데이터
students_data = {
    '등교시간': ['8:10', '8:15', '8:05', '8:20'],
    '학습언어': ['영어', '중국어', '일본어', '독일어', '프랑스어'],
    '도서관이용': ['07:30-09:00', '12:00-13:00', '18:00-21:00']
}

print("우리 학교 데이터를 확인해보자!")
print(f"학습 가능한 언어 수: {len(students_data['학습언어'])}개")

    실행 결과: 

    우리 학교 데이터를 확인해보자!
학습 가능한 언어 수: 5개

    📝 전체 코드¶

    # 외고생의 하루 - 데이터로 들여다보기
students_data = {
    '등교시간': ['8:10', '8:15', '8:05', '8:20'],
    '학습언어': ['영어', '중국어', '일본어', '독일어', '프랑스어'],
    '도서관이용': ['07:30-09:00', '12:00-13:00', '18:00-21:00']
}

print("🏫 외고생 데이터 분석 시작!")
print(f"📚 학습 가능한 언어: {len(students_data['학습언어'])}개")
print(f"⏰ 주요 등교 시간대: {len(students_data['등교시간'])}개 구간")
print("데이터 속에 숨은 이야기를 찾아보자! 🔍")

    ⚠️ 주의할 점¶

    • 데이터는 항상 실제 현실을 반영해야 의미가 있어요
    • 작은 데이터에서도 큰 인사이트를 발견할 수 있습니다

    ✅ 점검하기¶

    1. 데이터과학을 한 단어로 표현한다면?
    2. 우리 일상에서 데이터가 생성되는 순간을 3가지 말해보세요.
    정답 확인 1. 탐정! (데이터 속 숨은 이야기를 찾는 사람) 2. 예시: 휴대폰 사용시간, 급식 선택, 교통카드 이용 등
