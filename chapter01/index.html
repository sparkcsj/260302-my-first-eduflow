    Chapter 01: 흥미 유발: 데이터로 본 외고인의 하루¶

    Part 1: 데이터과학과의 첫 만남¶

    🎯 이 장에서 배우는 것¶

    • 일상 속 숨겨진 데이터를 발견할 수 있다
    • 데이터과학이 우리 생활과 연결되어 있음을 이해한다
    • 데이터를 통해 질문에 답하는 방법을 경험한다

    📚 핵심 개념¶

    개념: 데이터과학이란?¶

    데이터과학은 마치 탐정이 증거를 모아 사건을 푸는 것과 같아요. 주변에 흩어진 정보들(데이터)을 모아서 정렬하고, 패턴을 찾아 숨겨진 의미를 발견하는 과정입니다.

    정확한 정의: 데이터과학은 데이터를 수집·정리·분석하여 문제를 해결하고 의사결정을 돕는 학문입니다.

    생생한 예시:

    여러분의 외고 하루를 떠올려보세요. - 📱 등교 시간, 쉬는 시간에 하는 활동 - 📚 선택한 언어 종류, 수강 과목 - ⏰ 점심시간 식당 혼잡도

    이 모든 것이 데이터입니다! 이 데이터들을 모으면 "우리 학교의 패턴"이 보여요: - 오전 8시 20분에 등교생이 가장 많다 - 중국어를 배우는 학생이 가장 많다 - 금요일 저녁 7시에 독서실이 가장 비어있다

    이것이 바로 데이터과학입니다! 🔍

    🔨 따라하기¶

    Step 1: 외고생 등교 시간 데이터 살펴보기¶

    코드: 

    import matplotlib.pyplot as plt

# 외고생들의 등교 시간 데이터
times = ['7:50-8:00', '8:00-8:10', '8:10-8:20', '8:20-8:30']
students = [45, 82, 156, 98]  # 각 시간대 학생 수

plt.bar(times, students, color='skyblue')
plt.title('외고생 등교 시간 분포')
plt.xlabel('등교 시간')
plt.ylabel('학생 수')
plt.show()

    실행 결과: 막대 그래프가 나타나며, 8시 10분~20분 사이에 가장 많은 학생(156명)이 등교함을 한눈에 볼 수 있습니다! 📊

    Step 2: 패턴 발견하기¶

    코드: 

    # 가장 혼잡한 시간 찾기
max_time = times[students.index(max(students))]
print(f"가장 많은 학생이 등교한 시간: {max_time}")

    실행 결과: 

    가장 많은 학생이 등교한 시간: 8:10-8:20

    데이터 3줄로 문제를 풀었어요! 🎉

    📝 전체 코드¶

    import matplotlib.pyplot as plt

# 1. 데이터 준비
times = ['7:50-8:00', '8:00-8:10', '8:10-8:20', '8:20-8:30']
students = [45, 82, 156, 98]

# 2. 시각화
plt.bar(times, students, color='skyblue')
plt.title('외고생 등교 시간 분포')
plt.xlabel('등교 시간')
plt.ylabel('학생 수')
plt.show()

# 3. 분석
max_time = times[students.index(max(students))]
print(f"가장 많은 학생이 등교한 시간: {max_time}")

    ⚠️ 주의할 점¶

    1. 데이터의 정확성이 중요해요: 잘못된 데이터로 분석하면 잘못된 결론이 나옵니다. 탐정이 증거를 잘못 수집하면 범인을 못 잡는 것처럼요! 🕵️

    2. 데이터만으로는 부족해요: 왜 8시 20분에 몰릴까요? 이 질문은 데이터만으로는 못 답해요. 왜냐고 물어보는 습관을 들이세요!

    ✅ 점검하기¶

    1. 데이터과학이란 결국 무엇을 하는 학문인가요?
    정답 확인 데이터를 모아서 정렬하고 패턴을 찾아 숨겨진 의미와 답을 발견하는 것입니다.
    1. 위의 코드에서 발견한 가장 중요한 사실은 무엇인가요?
    정답 확인 외고생의 절반 이상(156명)이 8시 10분~20분 사이에 등교한다는 것입니다. 이를 통해 학교는 이 시간에 복도 혼잡을 대비할 수 있어요!
    1. 여러분의 일상에서 '데이터'라고 부를 수 있는 것 3가지를 찾아보세요.
    예시 📱 SNS에서 공유한 사진 개수, 📚 어제 푼 수학 문제 개수, ⏰ 하루 중 휴대폰 사용 시간 등
