    Chapter 01 | 데이터로 본 외고인의 하루¶

    🎯 이 장에서 배우는 것¶

    • 일상 속에서 데이터가 어떻게 만들어지는지 3가지 예시로 설명할 수 있다
    • 데이터과학이 무엇인지 자신의 말로 정의할 수 있다
    • 데이터과학이 문과 학생에게도 필요한 이유를 이해할 수 있다

    📚 핵심 개념¶

    개념 1: 데이터(Data)¶

    비유로 시작: "데이터는 마치 사진기가 찍은 현실의 장면들과 같아요"

    당신의 하루를 생각해보세요. 아침 7시에 일어나고, 스마트폰을 3시간 사용하고, 급식에서 된장찌개를 먹었습니다. 이 모든 것이 데이터입니다.

    정확한 정의: 데이터는 현실에서 관찰하거나 측정한 사실, 수치, 텍스트 같은 기록입니다. 숫자일 필요는 없습니다.

    실제 예시들: - 📱 스마트폰 스크린타임: 430분 (측정된 수치 → 데이터) - 🍜 오늘 급식 메뉴: 돈까스, 된장국, 나물반찬 (기록된 사실 → 데이터) - 📊 반 학생 50명의 MBTI: INTJ 8명, ENFP 7명... (분류된 정보 → 데이터)

    이렇게 흩어져 있는 사실들이 바로 데이터의 본모습입니다.

    개념 2: 데이터과학(Data Science)¶

    비유로 시작: "데이터과학은 마치 탐정이 증거들을 수집해서 범인을 찾는 것처럼, 데이터 속에서 숨겨진 진실을 찾아내는 거예요"

    정확한 정의: 데이터과학은 데이터를 수집, 정리, 분석하여 의미 있는 답변을 찾아내는 학문입니다.

    예를 들어: - 의문점: "우리 반 학생들이 점심시간에 가장 선호하는 급식 메뉴는?" - 데이터과학: 지난 3개월의 급식 메뉴와 섭취량 데이터를 모아 분석 - 결론: 카레 > 우동 > 돈까스 순 (분석 결과 도출)

    데이터과학은 단순한 계산이 아닙니다. 질문을 던지고 → 데이터를 찾고 → 의미를 해석하는 전체 과정입니다.

    개념 3: 문과적 사고가 데이터에 필수인 이유¶

    비유로 시작: "숫자는 눈 색깔, 이야기는 눈빛이에요. 둘 다 있어야 사람을 제대로 알죠"

    데이터과학은 수학만 잘한다고 되지 않습니다. 왜일까요?

    ✅ 문과 학생의 강점: - 맥락 읽기: "왜 이 수치가 나왔을까?" 배경을 파악 - 스토리텔링: 분석 결과를 다른 사람에게 설득력 있게 설명 - 질문 던지기: "우리가 정말 알아야 할 것이 뭘까?" 핵심 포착

    예시: 급식 선호도 분석 결과 "라면 선택률 0%"라는 수치가 나왔다면?

    ❌ 수치만 보는 관점: "라면은 못 팔았다" ✅ 맥락을 보는 관점: "라면은 급식에 없었다" 또는 "라면이 너무 자주 나와 학생들이 피했다"

    이 두 해석이 다른 이유는 상황을 읽는 능력 때문입니다. 이것은 문과적 사고입니다.

    🔨 따라하기¶

    Step 1: 외고인의 하루 데이터 모으기¶

    우리가 하루 동안 만드는 데이터를 실제로 확인해봅시다. Python을 열고 따라해보세요.

    # 외고인의 하루 데이터

# 기상부터 등교까지의 시간 데이터
morning_data = {
    "기상_시간": "06:30",
    "아침_준비_시간": 45,  # 분 단위
    "등교_시간": "07:45"
}

# 수업 중 스마트폰 사용 데이터
screen_time = {
    "1교시_사용시간": 0,
    "쉬는시간_1_사용시간": 8,  # 분
    "쉬는시간_2_사용시간": 10,
    "점심시간_사용시간": 35,
    "하루_총_사용시간": 430
}

# 급식 메뉴 데이터
lunch_data = {
    "주식": "흰쌀밥",
    "국": "된장국",
    "반찬": ["계란말이", "나물", "김"],
    "먹은_정도": "완식"  # 완식, 반쯤, 조금
}

print("📱 하루 스크린타임:", screen_time["하루_총_사용시간"], "분")
print("🍜 오늘 급식 메인:", lunch_data["국"])
print("✅ 기상 시간:", morning_data["기상_시간"])

    실행 결과: 

    📱 하루 스크린타임: 430 분
🍜 오늘 급식 메인: 된장국
✅ 기상 시간: 06:30

    Step 2: 반 학생 50명의 MBTI 데이터 분석하기¶

    이제 실제 데이터를 분석하는 과정을 경험해봅시다.

    # 반 학생 50명의 MBTI 분포 데이터
mbti_count = {
    "INTJ": 8,
    "INTP": 6,
    "ENTJ": 5,
    "ENTP": 4,
    "INFJ": 7,
    "INFP": 6,
    "ENFJ": 3,
    "ENFP": 5,
    "기타": 6
}

# 성향별 분류 (I/E로 구분)
introverts = mbti_count["INTJ"] + mbti_count["INTP"] + mbti_count["INFJ"] + mbti_count["INFP"]
extroverts = mbti_count["ENTJ"] + mbti_count["ENTP"] + mbti_count["ENFJ"] + mbti_count["ENFP"]

print(f"📊 우리 반 내향성 학생: {introverts}명 ({introverts/50*100:.1f}%)")
print(f"📊 우리 반 외향성 학생: {extroverts}명 ({extroverts/50*100:.1f}%)")
print(f"📊 가장 많은 유형: INTJ ({mbti_count['INTJ']}명)")

    실행 결과: 

    📊 우리 반 내향성 학생: 27명 (54.0%)
📊 우리 반 외향성 학생: 17명 (34.0%)
📊 가장 많은 유형: INTJ (8명)

    Step 3: 급식 메뉴 선호도 비교하기¶

    # 지난 1주일 급식 메뉴별 선호도 (5점 만점)
menu_preferences = {
    "카레": 4.8,
    "우동": 4.5,
    "돈까스": 4.2,
    "스파게티": 4.0,
    "비빔밥": 3.8,
    "라면": 2.5
}

# 가장 선호하는 메뉴
best_menu = max(menu_preferences, key=menu_preferences.get)
worst_menu = min(menu_preferences, key=menu_preferences.get)

print(f"🥇 가장 좋아하는 메뉴: {best_menu} ({menu_preferences[best_menu]}점)")
print(f"📉 가장 덜 좋아하는 메뉴: {worst_menu} ({menu_preferences[worst_menu]}점)")

# 의미 있는 해석
score_gap = menu_preferences[best_menu] - menu_preferences[worst_menu]
print(f"\n💭 생각해보기: 카레와 라면의 점수 차이가 {score_gap:.1f}점이나 난다면?")
print("→ 라면이 더 자주 나오기 때문일까? 아니면 질이 떨어지기 때문일까?")

    실행 결과: 

    🥇 가장 좋아하는 메뉴: 카레 (4.8점)
📉 가장 덜 좋아하는 메뉴: 라면 (2.5점)

💭 생각해보기: 카레와 라면의 점수 차이가 2.3점이나 난다면?
→ 라면이 더 자주 나오기 때문일까? 아니면 질이 떨어지기 때문일까?

    📝 전체 코드¶

    # ===== 외고인의 하루 데이터 분석 =====

# 1️⃣ 개별 학생의 하루 데이터
morning_data = {"기상_시간": "06:30", "등교_시간": "07:45"}
screen_time = {"1교시": 0, "쉬는시간": 18, "점심시간": 35, "총": 430}
lunch_data = {"주식": "흰쌀밥", "국": "된장국", "평가": "완식"}

print("=== 하루 생활 데이터 ===")
print(f"기상: {morning_data['기상_시간']}, 스크린타임: {screen_time['총']}분")

# 2️⃣ 반 전체 MBTI 분포
mbti_count = {"INTJ": 8, "INTP": 6, "ENTJ": 5, "ENTP": 4, 
              "INFJ": 7, "INFP": 6, "ENFJ": 3, "ENFP": 5, "기타": 6}
introverts = sum([mbti_count[k] for k in ["INTJ", "INTP", "INFJ", "INFP"]])
extroverts = sum([mbti_count[k] for k in ["ENTJ", "ENTP", "ENFJ", "ENFP"]])

print(f"\n=== MBTI 분석 ===")
print(f"내향성: {introverts}명, 외향성: {extroverts}명")

# 3️⃣ 급식 메뉴 선호도
menu = {"카레": 4.8, "우동": 4.5, "돈까스": 4.2, "라면": 2.5}
best = max(menu, key=menu.get)

print(f"\n=== 급식 분석 ===")
print(f"최고 선호 메뉴: {best} ({menu[best]}점)")
print("→ 이 수치가 높은 이유는 맛? 영양? 추억? (문과적 해석 필요!)")

    ⚠️ 주의할 점¶

    1. 데이터 ≠ 진실 - 데이터는 측정된 값일 뿐, 그것이 항상 맞는 것은 아닙니다 - 예: "라면 선호도 2.5점" → 실제로는 라면을 자주 먹어서 질린 것일 수도, 정말 못 먹어서일 수도 있음 - 항상 "왜?"라고 물어보세요

    2. 문맥 없는 숫자는 무의미합니다 - "스크린타임 430분" 하나로는 많은지 적은지 알 수 없음 - 어제는 360분이었는가? 전학년 평균은? 이런 비교가 있어야 의미 있음 - 데이터는 혼자가 아닌 함께 봐야 이해됩니다

    ✅ 점검하기¶

    1. 다음 중 데이터에 해당하는 것은 모두 고르세요 - ① 당신의 키: 167cm - ② 어제 수학 시험 점수: 92점 - ③ 가장 좋아하는 과목: 영어 - ④ 어제 걷는데 걸린 시간: 15분 - ⑤ "우리 반이 조용하다"는 누군가의 느낌

    정답 확인 **정답: ①, ②, ③, ④** - ① 측정된 수치 ✅ - ② 기록된 점수 ✅ - ③ 사실로 기록 가능한 정보 ✅ - ④ 측정된 시간 ✅ - ⑤ 개인의 주관적 느낌 (아직 데이터가 아님) ❌ "조용하다"를 데이터로 만들려면? "교시당 평균 소음도 50dB" 이렇게 측정해야 합니다!

    2. 데이터과학에서 문과 학생의 역할은?

    정답 확인 데이터과학에서 문과 학생은: ✅ **왜 이 질문이 중요한가?** 파악 → 주제 설정 ✅ **이 수치가 정말 맞나?** 검증 → 맥락 확인 ✅ **이 결과를 어떻게 설명할까?** 해석 → 스토리 구성 ✅ **어떤 행동을 해야 할까?** 제안 → 의사결정 지원 즉, **숫자를 의미 있게 만드는 역할**입니다!

    3. 다음 상황에서 어떤 추가 데이터가 필요할까요? "우리 반 학생들의 평균 스크린타임이 430분입니다"

    정답 확인 이 데이터만으로는 많은지 적은지 알 수 없습니다. 필요한 데이터: 📊 **비교 데이터** - 어제/지난주 평균과 비교 - 다른 반 평균과 비교 - 전체 고등학생 평균과 비교 📅 **맥락 데이터** - 측정 기간 (시험 기간? 휴일?) - 어떤 앱 사용 (공부? 게임? SNS?) - 학생별 편차 (누군가 800분? 누군가 100분?) → 이렇게 맥락을 채워야 "430분이 많다/적다"는 의미 있는 결론을 낼 수 있습니다!
