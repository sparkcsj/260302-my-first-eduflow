    Chapter 12. 수행평가 워크숍 ② - 내 데이터 전처리 & 시각화¶

    🎯 이 장에서 배우는 것¶

    • Colab에 내 데이터를 업로드하고 Pandas로 불러올 수 있다
    • 결측값과 이상값을 찾아서 처리할 수 있다
    • Matplotlib으로 2가지 이상의 그래프를 그려 비교할 수 있다
    • 시각화 결과에서 패턴을 발견하고 한 문장으로 설명할 수 있다

    💡 왜 이걸 배우나요?¶

    지금까지 배운 것들을 하나로 모으는 순간입니다. 당신이 직접 수집한 데이터를 정제하고 그림으로 그려내는 것은 데이터 분석가가 매일 하는 일이에요.

    생각해보세요. 당신이 학교 급식 만족도를 100명에게 조사했다고 합시다. 그런데: - 5명이 답변을 건너뛰었어요 (결측값) 🤷 - 한 명이 "999점"이라고 장난으로 썼어요 (이상값) 😂 - 남은 데이터를 어떻게 정리해야 할까요?

    이게 바로 "전처리(Preprocessing)"입니다. 데이터를 쓸 수 있는 상태로 만드는 작업이죠. 그리고 시각화는 그 결과를 한눈에 보여주는 마술입니다.

    이 장을 마치면, "나는 진짜 데이터 분석을 할 수 있다"는 자신감이 생길 거예요! 📊✨

    📚 핵심 개념¶

    개념 1: 결측값(Missing Value) - 비어있는 칸을 어떻게 할까?¶

    비유: 100명이 수강신청을 했는데 5명이 성적을 미제출한 상황. 이 5명의 성적을 어떻게 처리할 거예요?

    정확한 정의: 결측값은 데이터셋에서 값이 없거나 NaN(Not a Number)으로 표시된 부분입니다. 원인은 다양해요: - 응답자가 질문을 건너뜀 - 센서가 측정 실패 - 데이터 입력 실수

    처리 전략: - 삭제: 그 행 전체를 버림 (데이터가 많을 때 괜찮음) - 대체: 평균이나 중앙값으로 채움 (신중하게!) - 유지: 일단 두고 분석할 때 따로 처리

    예시: 

    # 결측값 확인
print(df.isnull().sum())  # 각 열의 결측값 개수

# 간단한 처리: 평균으로 채우기
df['키'].fillna(df['키'].mean(), inplace=True)

# 또는 그 행 삭제
df = df.dropna()

    개념 2: 이상값(Outlier) - 튀는 데이터를 잡아내기¶

    비유: 학급의 키를 조사했는데, 한 명이 "250cm"라고 답했다면? 분명히 뭔가 잘못됐지요.

    정확한 정의: 이상값은 다른 데이터들과 매우 다른, 극단적으로 크거나 작은 값입니다.

    찾는 방법: - 시각적: 상자 그림(Box plot)으로 보면 "수염" 밖의 점들 - 수치적: 1사분위수(Q1)와 3사분위수(Q3)를 이용한 IQR 방법

    IQR 방법 공식: - IQR = Q3 - Q1 - 하한 = Q1 - 1.5 × IQR - 상한 = Q3 + 1.5 × IQR - 이 범위를 벗어나면 이상값! 📍

    예시: 

    Q1 = df['나이'].quantile(0.25)
Q3 = df['나이'].quantile(0.75)
IQR = Q3 - Q1
하한 = Q1 - 1.5 * IQR
상한 = Q3 + 1.5 * IQR

# 이상값 찾기
이상값들 = df[(df['나이'] < 하한) | (df['나이'] > 상한)]
print(이상값들)

    개념 3: 시각화 선택 - 그래프는 데이터의 얼굴입니다¶

    비유: 같은 사람을 정면에서 찍은 사진과 옆면에서 찍은 사진이 다르게 보여요. 데이터도 마찬가지예요.

    상황별 그래프 선택:

    한 변수의 분포 보기 → 히스토그램(막대 그래프) - 예: "전교 학생들의 수학 성적이 어떻게 분포했나?"

    두 변수의 관계 보기 → 산점도(Scatter plot) - 예: "공부시간과 성적의 관계는?"

    범주별 평균 비교 → 막대그래프(Bar plot) - 예: "남학생과 여학생의 평균 키 비교"

    시간에 따른 변화 → 선 그래프(Line plot) - 예: "지난 1년간 스마트폰 가격 변동"

    이 장에서는 히스토그램 + 산점도 또는 막대그래프를 그려볼 거예요.

    개념 4: 인사이트 도출 - "그래프가 말해주는 것"¶

    비유: 엑스선 사진을 찍은 후 의사가 "뼈에 금이 갔네요"라고 진단하는 것처럼, 우리도 그래프를 읽고 해석해야 합니다.

    좋은 인사이트의 조건: - 📌 구체적: "키가 작다"(X) vs "남학생 평균이 여학생보다 5cm 크다"(O) - 🔍 근거 있음: 그래프에서 직접 확인 가능 - ⚡ 의미 있음: "그래서 뭐 어쨌는데?" 같은 질문에 답할 수 있어야 함

    예시: - ❌ "데이터가 많다" - ✅ "급식 만족도는 주중(평일)에는 평균 3.2점인데 금요일에는 4.1점으로 급상승한다"

    Step 2: 데이터 불러오기 & 확인¶

    # CSV 파일인 경우
df = pd.read_csv('당신의파일명.csv')

# Excel 파일인 경우
df = pd.read_excel('당신의파일명.xlsx')

# 처음 5행 보기
print(df.head())

# 데이터 크기 확인
print(df.shape)  # (행 수, 열 수)

# 각 열의 정보
print(df.info())

# 결측값 확인 ⭐
print(df.isnull().sum())

    Step 3: 결측값 처리¶

    상황 1: 결측값이 1-2개뿐이면 → 그 행 삭제

    df = df.dropna()
print(f"처리 후 행 수: {len(df)}")

    상황 2: 특정 열에만 결측값이 있으면 → 그 열만 처리

    # '키' 열에 결측값이 있으면 평균으로 채우기
df['키'].fillna(df['키'].mean(), inplace=True)

# '나이' 열에 결측값이 있으면 중앙값으로 채우기
df['나이'].fillna(df['나이'].median(), inplace=True)

    Step 4: 이상값 찾기 & 제거 (선택)¶

    # 예: '나이' 열에서 이상값 찾기
Q1 = df['나이'].quantile(0.25)
Q3 = df['나이'].quantile(0.75)
IQR = Q3 - Q1

하한 = Q1 - 1.5 * IQR
상한 = Q3 + 1.5 * IQR

# 이상값 개수 확인
이상값_개수 = ((df['나이'] < 하한) | (df['나이'] > 상한)).sum()
print(f"이상값 {이상값_개수}개 발견")

# 이상값 제거 (선택사항 - 신중하게!)
df = df[(df['나이'] >= 하한) & (df['나이'] <= 상한)]

    Step 5: 그래프 1 - 히스토그램으로 분포 보기¶

    plt.figure(figsize=(10, 6))

# 히스토그램: 한 변수의 분포
plt.hist(df['키'], bins=15, color='skyblue', edgecolor='black', alpha=0.7)

plt.xlabel('키 (cm)', fontsize=12)
plt.ylabel('학생 수', fontsize=12)
plt.title('학생 키의 분포', fontsize=14, fontweight='bold')
plt.grid(axis='y', alpha=0.3)

plt.tight_layout()
plt.show()

# 📝 발견: 평균은? 가장 많은 학생의 키는?
print(f"평균 키: {df['키'].mean():.1f}cm")
print(f"중앙값: {df['키'].median():.1f}cm")
print(f"표준편차: {df['키'].std():.1f}cm")

    Step 6: 그래프 2 - 산점도 또는 막대그래프로 관계 보기¶

    선택A: 산점도 (두 수치 변수의 관계)

    plt.figure(figsize=(10, 6))

# 산점도: 공부시간과 성적의 관계
plt.scatter(df['공부시간'], df['성적'], 
           s=100, alpha=0.6, color='coral', edgecolor='black')

plt.xlabel('공부시간 (시간/주)', fontsize=12)
plt.ylabel('성적 (점)', fontsize=12)
plt.title('공부시간과 성적의 관계', fontsize=14, fontweight='bold')
plt.grid(alpha=0.3)

plt.tight_layout()
plt.show()

# 📝 발견: 상관관계가 있나?
상관계수 = df['공부시간'].corr(df['성적'])
print(f"상관계수: {상관계수:.2f}")

    선택B: 막대그래프 (범주별 평균 비교)

    plt.figure(figsize=(10, 6))

# 범주별 평균 계산
평균들 = df.groupby('성별')['키'].mean()

# 막대그래프
bars = plt.bar(평균들.index, 평균들.values, color=['#FF6B9D', '#4A90E2'], edgecolor='black')

plt.ylabel('평균 키 (cm)', fontsize=12)
plt.title('성별에 따른 평균 키', fontsize=14, fontweight='bold')
plt.ylim(0, 200)

# 막대 위에 숫자 표시
for bar in bars:
    height = bar.get_height()
    plt.text(bar.get_x() + bar.get_width()/2., height,
            f'{height:.1f}cm', ha='center', va='bottom', fontsize=11)

plt.tight_layout()
plt.show()

# 📝 발견
print(f"성별별 평균:\n{평균들}")

    📝 전체 코드¶

    한 번에 실행할 수 있는 완성 코드:

    import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

plt.rcParams['font.family'] = 'DejaVu Sans'

# ===== Step 1-2: 데이터 불러오기 =====
df = pd.read_csv('당신의파일명.csv')
print("=== 데이터 확인 ===")
print(df.head())
print(f"\n크기: {df.shape}")
print(f"\n결측값:\n{df.isnull().sum()}")

# ===== Step 3: 결측값 처리 =====
print("\n=== 결측값 처리 중... ===")
df = df.dropna()
print(f"처리 후 행 수: {len(df)}")

# ===== Step 5: 그래프 1 - 히스토그램 =====
print("\n=== 그래프 1: 히스토그램 ===")
plt.figure(figsize=(10, 6))
plt.hist(df['키'], bins=15, color='skyblue', edgecolor='black', alpha=0.7)
plt.xlabel('키 (cm)', fontsize=12)
plt.ylabel('학생 수', fontsize=12)
plt.title('학생 키의 분포', fontsize=14, fontweight='bold')
plt.grid(axis='y', alpha=0.3)
plt.tight_layout()
plt.show()

print(f"평균: {df['키'].mean():.1f}cm")
print(f"중앙값: {df['키'].median():.1f}cm")

# ===== Step 6: 그래프 2 - 산점도 =====
print("\n=== 그래프 2: 산점도 ===")
plt.figure(figsize=(10, 6))
plt.scatter(df['공부시간'], df['성적'], s=100, alpha=0.6, color='coral', edgecolor='black')
plt.xlabel('공부시간 (시간/주)', fontsize=12)
plt.ylabel('성적 (점)', fontsize=12)
plt.title('공부시간과 성적의 관계', fontsize=14, fontweight='bold')
plt.grid(alpha=0.3)
plt.tight_layout()
plt.show()

상관계수 = df['공부시간'].corr(df['성적'])
print(f"상관계수: {상관계수:.2f}")

    ✅ 스스로 점검하기¶

    완료된 항목에 ✓ 표시하세요:

    데이터 전처리 부분 - [ ] CSV/Excel 파일을 성공적으로 업로드하고 불러왔다 - [ ] df.head()와 df.info()로 데이터 구조를 확인했다 - [ ] df.isnull().sum()으로 결측값을 찾았다 - [ ] 결측값을 처리했다 (삭제 또는 대체) - [ ] 이상값을 확인했다 (최소 한 번은)

    시각화 부분 - [ ] 그래프 1 (히스토그램)을 그렸다 - [ ] 그래프 2 (산점도 또는 막대그래프)를 그렸다 - [ ] 각 그래프의 제목과 축 레이블을 명확하게 작성했다 - [ ] 그래프 이미지를 스크린샷으로 저장했다

    인사이트 부분 - [ ] 두 그래프에서 발견한 패턴을 각각 찾았다 - [ ] 발견한 내용을 "~하다"로 끝나는 한 문장으로 작성했다 - [ ] 그 문장이 그래프에서 직접 확인 가능한 내용이다
